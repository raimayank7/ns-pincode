About PIN code 605004

PIN code 605004 belongs to Pondicherry, Puducherry. It is used by 4 post offices: Mudaliarpet, Pondicherry Courts, Mouroungapakkam, Thengaithittu. 1 office delivers post to homes: Mudaliarpet. The others only serve customers at the counter.

What the digits of 605004 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 60: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 605: the first three digits name the sorting district, where post for this area is sorted.
  • 004: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Pondicherry, Puducherry - 605004. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
