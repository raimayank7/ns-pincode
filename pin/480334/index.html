About PIN code 480334

PIN code 480334 belongs to Chhindwara, Madhya Pradesh. It is used by 19 post offices: Pandhurna, Ambada Pandhurna, Bhandargondi, Changoba and others. 18 offices deliver post to homes: Pandhurna, Ambada Pandhurna, Bhandargondi, Changoba, Dadimeta and others. The others only serve customers at the counter.

What the digits of 480334 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 48: the first two digits together name the sub-zone, here the Madhya Pradesh Circle.
  • 480: the first three digits name the sorting district, where post for this area is sorted.
  • 334: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Chhindwara, Madhya Pradesh - 480334. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
