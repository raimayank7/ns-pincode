About PIN code 610204

PIN code 610204 belongs to Nagapattinam, Tamil Nadu. It is used by 4 post offices: Tirukuvalai, Ettukudi, Melavazhakarai, Tiruvoimur. Every one of them delivers post to homes.

What the digits of 610204 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 61: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 610: the first three digits name the sorting district, where post for this area is sorted.
  • 204: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nagapattinam, Tamil Nadu - 610204. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
