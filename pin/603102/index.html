About PIN code 603102

PIN code 603102 belongs to Chengalpattu, Tamil Nadu. It is used by 11 post offices: Kalpakkam, Pudupattinam Colony, Ayapakkam, Manamai and others. 9 offices deliver post to homes: Kalpakkam, Ayapakkam, Manamai, Melperumalcheri, Pattaraikalani and others. The others only serve customers at the counter.

What the digits of 603102 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 60: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 603: the first three digits name the sorting district, where post for this area is sorted.
  • 102: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Chengalpattu, Tamil Nadu - 603102. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
