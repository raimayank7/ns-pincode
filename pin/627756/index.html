About PIN code 627756

PIN code 627756 belongs to Tenkasi, Tamil Nadu. It is used by 2 post offices: Sankarankovil, Sankarankovil Bazaar. 1 office delivers post to homes: Sankarankovil. The others only serve customers at the counter.

What the digits of 627756 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 62: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 627: the first three digits name the sorting district, where post for this area is sorted.
  • 756: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Tenkasi, Tamil Nadu - 627756. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
