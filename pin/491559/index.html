About PIN code 491559

PIN code 491559 belongs to Kabirdham, Chhattisgarh. It is used by 38 post offices: Pandaria, BADNA, BHELKI, Bagharra and others. Every one of them delivers post to homes.

What the digits of 491559 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 49: the first two digits together name the sub-zone, here the Chattisgarh Circle.
  • 491: the first three digits name the sorting district, where post for this area is sorted.
  • 559: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kabirdham, Chhattisgarh - 491559. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
