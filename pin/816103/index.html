About PIN code 816103

PIN code 816103 belongs to Pakur, Jharkhand. It is used by 16 post offices: Benagaria, Banspahari, Banspahari, Catupara and others. Every one of them delivers post to homes.

What the digits of 816103 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 81: the first two digits together name the sub-zone, here the Jharkhand Circle.
  • 816: the first three digits name the sorting district, where post for this area is sorted.
  • 103: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Pakur, Jharkhand - 816103. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
