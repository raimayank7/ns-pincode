About PIN code 573165

PIN code 573165 belongs to Hassan, Karnataka. It is used by 6 post offices: Hanbalu, Devaladakere, Hadige, Hurudi and others. Every one of them delivers post to homes.

What the digits of 573165 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 57: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 573: the first three digits name the sorting district, where post for this area is sorted.
  • 165: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Hassan, Karnataka - 573165. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
