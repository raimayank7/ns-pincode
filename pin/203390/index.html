About PIN code 203390

PIN code 203390 belongs to Bulandshahr, Uttar Pradesh. It is used by 12 post offices: Anupshahr, Bagsara, Bhargava Pharmecy, Bhopatpur and others. 11 offices deliver post to homes: Anupshahr, Bagsara, Bhopatpur, Bibiyana, Birauli and others. The others only serve customers at the counter.

What the digits of 203390 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 20: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 203: the first three digits name the sorting district, where post for this area is sorted.
  • 390: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Bulandshahr, Uttar Pradesh - 203390. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
