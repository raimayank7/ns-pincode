About PIN code 844114

PIN code 844114 belongs to Vaishali, Bihar. It is used by 17 post offices: Bhagwanpur SO Vaishali, Asoi, Bishanpur Bande, Bithauli and others. Every one of them delivers post to homes.

What the digits of 844114 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 84: the first two digits together name the sub-zone, here the Bihar Circle.
  • 844: the first three digits name the sorting district, where post for this area is sorted.
  • 114: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Vaishali, Bihar - 844114. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
