About PIN code 285203

PIN code 285203 belongs to Jalaun, Uttar Pradesh. It is used by 16 post offices: Baoni Estate, Alipur, Babina, Bagi and others. Every one of them delivers post to homes.

What the digits of 285203 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 28: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 285: the first three digits name the sorting district, where post for this area is sorted.
  • 203: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Jalaun, Uttar Pradesh - 285203. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
