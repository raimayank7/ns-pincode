About PIN code 585214

PIN code 585214 belongs to Yadgir, Karnataka. It is used by 22 post offices: Gurmitkal, Budur, Buragpalli, Chandarki and others. 21 offices deliver post to homes: Gurmitkal, Budur, Buragpalli, Chandarki, Chepatla and others. The others only serve customers at the counter.

What the digits of 585214 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 58: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 585: the first three digits name the sorting district, where post for this area is sorted.
  • 214: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Yadgir, Karnataka - 585214. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
