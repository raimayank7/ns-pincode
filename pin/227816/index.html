About PIN code 227816

PIN code 227816 belongs to Amethi, Uttar Pradesh. It is used by 16 post offices: Raniganj SO Sultanpur, Baharpur, Barsanda, Deokali and others. Every one of them delivers post to homes.

What the digits of 227816 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 22: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 227: the first three digits name the sorting district, where post for this area is sorted.
  • 816: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Amethi, Uttar Pradesh - 227816. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
