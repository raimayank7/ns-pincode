About PIN code 451114

PIN code 451114 belongs to Khargone, Madhya Pradesh. It is used by 6 post offices: SELDA, Ahirkheda, Anjangaon, Chhirwa and others. Every one of them delivers post to homes.

What the digits of 451114 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 45: the first two digits together name the sub-zone, here the Madhya Pradesh Circle.
  • 451: the first three digits name the sorting district, where post for this area is sorted.
  • 114: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Khargone, Madhya Pradesh - 451114. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
