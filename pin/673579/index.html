About PIN code 673579

PIN code 673579 belongs to Wayanad, Kerala. It is used by 18 post offices: Pulpalli, Amara Kuni, Bhoodanam Colony, Cheeyambam and others. Every one of them delivers post to homes.

What the digits of 673579 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 67: the first two digits together name the sub-zone, here the Kerala Circle.
  • 673: the first three digits name the sorting district, where post for this area is sorted.
  • 579: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Wayanad, Kerala - 673579. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
