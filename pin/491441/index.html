About PIN code 491441

PIN code 491441 belongs to Rajnandgaon, Chhattisgarh. It is used by 69 post offices: Rajnandgaon, Bazar Rajnadngaon, G G Chowk Rajnandgaon, Rajnandgaon Kutchery and others. 64 offices deliver post to homes: Rajnandgaon, Aargaon, Arjuni, Baghera, Bajrangpur Nawagaon and others. The others only serve customers at the counter.

What the digits of 491441 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 49: the first two digits together name the sub-zone, here the Chattisgarh Circle.
  • 491: the first three digits name the sorting district, where post for this area is sorted.
  • 441: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Rajnandgaon, Chhattisgarh - 491441. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
