About PIN code 811201

PIN code 811201 belongs to Munger, Bihar. It is used by 9 post offices: Munger, Belan Bazar, Ganga Darshan, Lal Darwaza SO Munger and others. 2 offices deliver post to homes: Munger, Jamalpur WS. The others only serve customers at the counter.

What the digits of 811201 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 81: the first two digits together name the sub-zone, here the Bihar Circle.
  • 811: the first three digits name the sorting district, where post for this area is sorted.
  • 201: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Munger, Bihar - 811201. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
