About PIN code 852112

PIN code 852112 belongs to Madhepura, Bihar. It is used by 19 post offices: Kumarkhand, BKorhlahi, Besarh, Bhatni and others. Every one of them delivers post to homes.

What the digits of 852112 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 85: the first two digits together name the sub-zone, here the Bihar Circle.
  • 852: the first three digits name the sorting district, where post for this area is sorted.
  • 112: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Madhepura, Bihar - 852112. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
