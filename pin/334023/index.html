About PIN code 334023

PIN code 334023 belongs to Bikaner, Rajasthan. It is used by 10 post offices: Khajuwala, 17 K.Y.D, 2 K.L.D, 34 KYD and others. Every one of them delivers post to homes.

What the digits of 334023 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 33: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 334: the first three digits name the sorting district, where post for this area is sorted.
  • 023: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Bikaner, Rajasthan - 334023. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
