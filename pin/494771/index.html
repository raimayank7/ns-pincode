About PIN code 494771

PIN code 494771 belongs to Kanker, Chhattisgarh. It is used by 30 post offices: Chotekapsi, Alor, Badejharkatta, Badgaon and others. Every one of them delivers post to homes.

What the digits of 494771 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 49: the first two digits together name the sub-zone, here the Chattisgarh Circle.
  • 494: the first three digits name the sorting district, where post for this area is sorted.
  • 771: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kanker, Chhattisgarh - 494771. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
