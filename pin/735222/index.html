About PIN code 735222

PIN code 735222 belongs to Jalpaiguri, West Bengal. It is used by 3 post offices: Manabari, Oodlabari, Patharjhora. Every one of them delivers post to homes.

What the digits of 735222 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 73: the first two digits together name the sub-zone, here the West Bengal Circle.
  • 735: the first three digits name the sorting district, where post for this area is sorted.
  • 222: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Jalpaiguri, West Bengal - 735222. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
