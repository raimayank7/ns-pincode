About PIN code 571234

PIN code 571234 belongs to Kodagu, Karnataka. It is used by 10 post offices: Kushalnagar, Baichanahally, Basavanahally, Guddehosur and others. 9 offices deliver post to homes: Kushalnagar, Baichanahally, Basavanahally, Guddehosur, Harangi Project and others. The others only serve customers at the counter.

What the digits of 571234 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 57: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 571: the first three digits name the sorting district, where post for this area is sorted.
  • 234: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kodagu, Karnataka - 571234. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
