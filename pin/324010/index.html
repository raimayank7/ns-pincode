About PIN code 324010

PIN code 324010 belongs to Kota, Rajasthan. It is used by 5 post offices: Engineering College Kota, Borabas, Chand Baori, Dolya and others. Every one of them delivers post to homes.

What the digits of 324010 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 32: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 324: the first three digits name the sorting district, where post for this area is sorted.
  • 010: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kota, Rajasthan - 324010. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
