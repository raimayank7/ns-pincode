About PIN code 194301

PIN code 194301 belongs to Kargil, Ladakh. It is used by 7 post offices: Sankoo, Barsoo, Khasgam Thuina, Lankarchey and others. Every one of them delivers post to homes.

What the digits of 194301 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 19: the first two digits together name the sub-zone, here the Jammu Kashmir Circle.
  • 194: the first three digits name the sorting district, where post for this area is sorted.
  • 301: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kargil, Ladakh - 194301. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
