About PIN code 736207

PIN code 736207 belongs to Alipurduar, West Bengal. It is used by 6 post offices: Barobisha, Baruipara, Jorai, Purba Shalbari and others. Every one of them delivers post to homes.

What the digits of 736207 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 73: the first two digits together name the sub-zone, here the West Bengal Circle.
  • 736: the first three digits name the sorting district, where post for this area is sorted.
  • 207: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Alipurduar, West Bengal - 736207. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
