About PIN code 722151

PIN code 722151 belongs to Bankura, West Bengal. It is used by 16 post offices: Simlapal, Baricha, Bhedua, Bikrampur and others. Every one of them delivers post to homes.

What the digits of 722151 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 72: the first two digits together name the sub-zone, here the West Bengal Circle.
  • 722: the first three digits name the sorting district, where post for this area is sorted.
  • 151: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Bankura, West Bengal - 722151. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
