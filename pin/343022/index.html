About PIN code 343022

PIN code 343022 belongs to Jalore, Rajasthan. It is used by 11 post offices: Sayla S.O (Jalor), Asana, Babtra, Bhundwa and others. Every one of them delivers post to homes.

What the digits of 343022 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 34: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 343: the first three digits name the sorting district, where post for this area is sorted.
  • 022: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Jalore, Rajasthan - 343022. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
