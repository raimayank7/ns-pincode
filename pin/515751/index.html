About PIN code 515751

PIN code 515751 belongs to Anantapur, Andhra Pradesh. It is used by 14 post offices: Atmakur(ATP), Goridindla, Kamarupalli, Kothapalli and others. Every one of them delivers post to homes.

What the digits of 515751 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 51: the first two digits together name the sub-zone, here the Andhra Pradesh Circle.
  • 515: the first three digits name the sorting district, where post for this area is sorted.
  • 751: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Anantapur, Andhra Pradesh - 515751. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
