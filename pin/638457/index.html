About PIN code 638457

PIN code 638457 belongs to Erode, Tamil Nadu. It is used by 4 post offices: Kurumandur, AlingiamGobi, Karattupalayam, Kummakalipalayam. Every one of them delivers post to homes.

What the digits of 638457 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 63: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 638: the first three digits name the sorting district, where post for this area is sorted.
  • 457: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Erode, Tamil Nadu - 638457. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
