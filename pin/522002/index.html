About PIN code 522002

PIN code 522002 belongs to Guntur, Andhra Pradesh. It is used by 2 post offices: Guntur, Brodipet(Guntur). 1 office delivers post to homes: Guntur. The others only serve customers at the counter.

What the digits of 522002 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 52: the first two digits together name the sub-zone, here the Andhra Pradesh Circle.
  • 522: the first three digits name the sorting district, where post for this area is sorted.
  • 002: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Guntur, Andhra Pradesh - 522002. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
