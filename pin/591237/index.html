About PIN code 591237

PIN code 591237 belongs to Belagavi, Karnataka. It is used by 12 post offices: Nipani, Arjunnagar, Chikalwal, Gondikuppi and others. 11 offices deliver post to homes: Nipani, Arjunnagar, Chikalwal, Gondikuppi, Jatrat and others. The others only serve customers at the counter.

What the digits of 591237 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 59: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 591: the first three digits name the sorting district, where post for this area is sorted.
  • 237: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Belagavi, Karnataka - 591237. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
