About PIN code 741138

PIN code 741138 belongs to Nadia, West Bengal. It is used by 4 post offices: Dharmada, Billwagram, Kandoa, Tentulberia. Every one of them delivers post to homes.

What the digits of 741138 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 74: the first two digits together name the sub-zone, here the West Bengal Circle.
  • 741: the first three digits name the sorting district, where post for this area is sorted.
  • 138: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nadia, West Bengal - 741138. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
