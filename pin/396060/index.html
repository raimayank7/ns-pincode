About PIN code 396060

PIN code 396060 belongs to Navsari, Gujarat. It is used by 15 post offices: Rumla, Agasi, Dhamdhuma, Dholumber Chikhli and others. Every one of them delivers post to homes.

What the digits of 396060 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 39: the first two digits together name the sub-zone, here the Gujarat Circle.
  • 396: the first three digits name the sorting district, where post for this area is sorted.
  • 060: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Navsari, Gujarat - 396060. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
