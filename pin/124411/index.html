About PIN code 124411

PIN code 124411 belongs to Rohtak, Haryana. It is used by 5 post offices: Anwal, Banyani, Garhi Ballab, Lahli and others. Every one of them delivers post to homes.

What the digits of 124411 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 12: the first two digits together name the sub-zone, here the Haryana Circle.
  • 124: the first three digits name the sorting district, where post for this area is sorted.
  • 411: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Rohtak, Haryana - 124411. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
