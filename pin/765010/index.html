About PIN code 765010

PIN code 765010 belongs to Rayagada, Odisha. It is used by 1 post office (Kolnara). It delivers post to homes.

What the digits of 765010 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 76: the first two digits together name the sub-zone, here the Odisha Circle.
  • 765: the first three digits name the sorting district, where post for this area is sorted.
  • 010: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Rayagada, Odisha - 765010. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
