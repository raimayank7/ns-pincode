About PIN code 576213

PIN code 576213 belongs to Udupi, Karnataka. It is used by 11 post offices: Brahmavara, Aroor, Baikadi, Chanthar and others. 10 offices deliver post to homes: Brahmavara, Aroor, Chanthar, Haradi, Herur and others. The others only serve customers at the counter.

What the digits of 576213 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 57: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 576: the first three digits name the sorting district, where post for this area is sorted.
  • 213: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Udupi, Karnataka - 576213. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
