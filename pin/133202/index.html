About PIN code 133202

PIN code 133202 belongs to Ambala, Haryana. It is used by 5 post offices: Dhin, Alipur Jahangir, Duliani, Manka Manki and others. Every one of them delivers post to homes.

What the digits of 133202 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 13: the first two digits together name the sub-zone, here the Haryana Circle.
  • 133: the first three digits name the sorting district, where post for this area is sorted.
  • 202: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ambala, Haryana - 133202. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
