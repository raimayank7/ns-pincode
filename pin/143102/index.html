About PIN code 143102

PIN code 143102 belongs to Amritsar, Punjab. It is used by 20 post offices: Ajnala, Balharwal, Bhallapind, Bhoewali and others. 19 offices deliver post to homes: Ajnala, Balharwal, Bhallapind, Bhoewali, Fatehwal and others. The others only serve customers at the counter.

What the digits of 143102 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 14: the first two digits together name the sub-zone, here the Punjab Circle.
  • 143: the first three digits name the sorting district, where post for this area is sorted.
  • 102: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Amritsar, Punjab - 143102. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
