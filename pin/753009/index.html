About PIN code 753009

PIN code 753009 belongs to Cuttack, Odisha. It is used by 2 post offices: Rajabagicha, Telenga Bazar. 1 office delivers post to homes: Telenga Bazar. The others only serve customers at the counter.

What the digits of 753009 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 75: the first two digits together name the sub-zone, here the Odisha Circle.
  • 753: the first three digits name the sorting district, where post for this area is sorted.
  • 009: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Cuttack, Odisha - 753009. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
