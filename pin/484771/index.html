About PIN code 484771

PIN code 484771 belongs to Shahdol, Madhya Pradesh. It is used by 30 post offices: Jaisinghnagar, Amdih, Amjhor, Bansa and others. Every one of them delivers post to homes.

What the digits of 484771 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 48: the first two digits together name the sub-zone, here the Madhya Pradesh Circle.
  • 484: the first three digits name the sorting district, where post for this area is sorted.
  • 771: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Shahdol, Madhya Pradesh - 484771. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
