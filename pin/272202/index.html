About PIN code 272202

PIN code 272202 belongs to Siddharth Nagar, Uttar Pradesh. It is used by 9 post offices: Birdpur, Alidapur, Birdpur No7, Bishunpurwa and others. Every one of them delivers post to homes.

What the digits of 272202 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 27: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 272: the first three digits name the sorting district, where post for this area is sorted.
  • 202: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Siddharth Nagar, Uttar Pradesh - 272202. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
