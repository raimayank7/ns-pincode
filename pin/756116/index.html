About PIN code 756116

PIN code 756116 belongs to Bhadrak, Odisha. It is used by 15 post offices: Arnapal, Anandabazar, Balabhadrapur, Bishnupurbindha and others. Every one of them delivers post to homes.

What the digits of 756116 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 75: the first two digits together name the sub-zone, here the Odisha Circle.
  • 756: the first three digits name the sorting district, where post for this area is sorted.
  • 116: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Bhadrak, Odisha - 756116. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
