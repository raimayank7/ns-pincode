About PIN code 494334

PIN code 494334 belongs to Raipur, Chhattisgarh. It is used by 33 post offices: Kanker, Kanker Kutchery, Anjani, Aturgaon and others. 32 offices deliver post to homes: Kanker, Anjani, Aturgaon, Bagodar, Bewarti and others. The others only serve customers at the counter.

What the digits of 494334 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 49: the first two digits together name the sub-zone, here the Chattisgarh Circle.
  • 494: the first three digits name the sorting district, where post for this area is sorted.
  • 334: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Raipur, Chhattisgarh - 494334. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
