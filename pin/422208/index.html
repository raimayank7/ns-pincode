About PIN code 422208

PIN code 422208 belongs to Nashik, Maharashtra. It is used by 19 post offices: Peint, Amba (Peint), Asarbari, Bhuvan and others. Every one of them delivers post to homes.

What the digits of 422208 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 42: the first two digits together name the sub-zone, here the Maharashtra Circle.
  • 422: the first three digits name the sorting district, where post for this area is sorted.
  • 208: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nashik, Maharashtra - 422208. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
