About PIN code 583119

PIN code 583119 belongs to Ballari, Karnataka. It is used by 8 post offices: Lakshmipura Sandur, Sandur, Bhujanganagar, Dawlatpur and others. 7 offices deliver post to homes: Sandur, Bhujanganagar, Dawlatpur, Krishna Nagar, Nandihalli and others. The others only serve customers at the counter.

What the digits of 583119 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 58: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 583: the first three digits name the sorting district, where post for this area is sorted.
  • 119: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ballari, Karnataka - 583119. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
