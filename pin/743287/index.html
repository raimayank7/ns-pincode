About PIN code 743287

PIN code 743287 belongs to 24 Paraganas North, West Bengal. It is used by 3 post offices: Thakurnagar, Chikanpara, Colony Ramchandra Pur. Every one of them delivers post to homes.

What the digits of 743287 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 74: the first two digits together name the sub-zone, here the West Bengal Circle.
  • 743: the first three digits name the sorting district, where post for this area is sorted.
  • 287: the last three digits name the delivery post office within that sorting district.

Writing this address
