About PIN code 491995

PIN code 491995 belongs to Kabirdham, Chhattisgarh. It is used by 44 post offices: Kawardha, Kawardha Collectorate, BAHNAKHODRA, BENDARCHI and others. 43 offices deliver post to homes: Kawardha, BAHNAKHODRA, BENDARCHI, BIRUTOLA, BOKKARKHAR and others. The others only serve customers at the counter.

What the digits of 491995 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 49: the first two digits together name the sub-zone, here the Chattisgarh Circle.
  • 491: the first three digits name the sorting district, where post for this area is sorted.
  • 995: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kabirdham, Chhattisgarh - 491995. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
