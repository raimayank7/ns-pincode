About PIN code 460220

PIN code 460220 belongs to Betul, Madhya Pradesh. It is used by 39 post offices: Bhainsdehi, Badgaon Bhaisdehi, Bakud, Barhapur and others. Every one of them delivers post to homes.

What the digits of 460220 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 46: the first two digits together name the sub-zone, here the Madhya Pradesh Circle.
  • 460: the first three digits name the sorting district, where post for this area is sorted.
  • 220: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Betul, Madhya Pradesh - 460220. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
