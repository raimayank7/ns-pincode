About PIN code 532460

PIN code 532460 belongs to Parvathipuram Manyam, Andhra Pradesh. It is used by 22 post offices: Veeraghattam, CHALIVENDRI, Chidimi, Chittapudivalasa and others. Every one of them delivers post to homes.

What the digits of 532460 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 53: the first two digits together name the sub-zone, here the Andhra Pradesh Circle.
  • 532: the first three digits name the sorting district, where post for this area is sorted.
  • 460: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Parvathipuram Manyam, Andhra Pradesh - 532460. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
