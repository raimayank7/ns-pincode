About PIN code 581412

PIN code 581412 belongs to Uttara Kannada, Karnataka. It is used by 3 post offices: Kirwatti, Hosalli, Madnoor. Every one of them delivers post to homes.

What the digits of 581412 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 58: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 581: the first three digits name the sorting district, where post for this area is sorted.
  • 412: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Uttara Kannada, Karnataka - 581412. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
