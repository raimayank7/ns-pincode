About PIN code 341511

PIN code 341511 belongs to Nagaur, Rajasthan. It is used by 10 post offices: Merta Road, Chhapri, Datani, Dhadhwara and others. Every one of them delivers post to homes.

What the digits of 341511 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 34: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 341: the first three digits name the sorting district, where post for this area is sorted.
  • 511: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nagaur, Rajasthan - 341511. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
