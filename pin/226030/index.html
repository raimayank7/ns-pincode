About PIN code 226030

PIN code 226030 belongs to Lucknow, Uttar Pradesh. It is used by 1 post office (Sushant Golf City). It delivers post to homes.

What the digits of 226030 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 22: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 226: the first three digits name the sorting district, where post for this area is sorted.
  • 030: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Lucknow, Uttar Pradesh - 226030. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
