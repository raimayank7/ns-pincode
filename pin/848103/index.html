About PIN code 848103

PIN code 848103 belongs to Samastipur, Bihar. It is used by 8 post offices: Musrigharari, BRBCollege, BhDhurlak, Harpur Ailoth and others. 7 offices deliver post to homes: Musrigharari, BhDhurlak, Harpur Ailoth, LBPura, Lagunia Raghukanth and others. The others only serve customers at the counter.

What the digits of 848103 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 84: the first two digits together name the sub-zone, here the Bihar Circle.
  • 848: the first three digits name the sorting district, where post for this area is sorted.
  • 103: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Samastipur, Bihar - 848103. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
