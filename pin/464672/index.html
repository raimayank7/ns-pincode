About PIN code 464672

PIN code 464672 belongs to Raisen, Madhya Pradesh. It is used by 8 post offices: Bamhori, Jamuniya Ganeshram, Keeratpur, Kuchwada and others. Every one of them delivers post to homes.

What the digits of 464672 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 46: the first two digits together name the sub-zone, here the Madhya Pradesh Circle.
  • 464: the first three digits name the sorting district, where post for this area is sorted.
  • 672: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Raisen, Madhya Pradesh - 464672. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
