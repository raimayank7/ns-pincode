About PIN code 535145

PIN code 535145 belongs to Visakhapatanam, Andhra Pradesh. It is used by 27 post offices: S Kota, Ananthagiri, B G Valasa, Bheempolu and others. Every one of them delivers post to homes.

What the digits of 535145 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 53: the first two digits together name the sub-zone, here the Andhra Pradesh Circle.
  • 535: the first three digits name the sorting district, where post for this area is sorted.
  • 145: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Visakhapatanam, Andhra Pradesh - 535145. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
