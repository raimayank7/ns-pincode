About PIN code 413713

PIN code 413713 belongs to Ahmednagar, Maharashtra. It is used by 1 post office (Loni Kd). It delivers post to homes.

What the digits of 413713 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 41: the first two digits together name the sub-zone, here the Maharashtra Circle.
  • 413: the first three digits name the sorting district, where post for this area is sorted.
  • 713: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ahmednagar, Maharashtra - 413713. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
