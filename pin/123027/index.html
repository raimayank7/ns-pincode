About PIN code 123027

PIN code 123027 belongs to Mahendragarh, Haryana. It is used by 17 post offices: Kanina, Baghot, Bharaf, Chitrauli and others. 9 offices deliver post to homes: Kanina, Chitrauli, Dhanaunda, Gurha, Kheri and others. The others only serve customers at the counter.

What the digits of 123027 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 12: the first two digits together name the sub-zone, here the Haryana Circle.
  • 123: the first three digits name the sorting district, where post for this area is sorted.
  • 027: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Mahendragarh, Haryana - 123027. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
