About PIN code 854202

PIN code 854202 belongs to Purnia, Bihar. It is used by 18 post offices: Banmankhi, Aurahi Gobindpur, Bhatgama, Bishanpur Dutt and others. Every one of them delivers post to homes.

What the digits of 854202 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 85: the first two digits together name the sub-zone, here the Bihar Circle.
  • 854: the first three digits name the sorting district, where post for this area is sorted.
  • 202: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Purnia, Bihar - 854202. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
