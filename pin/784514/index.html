About PIN code 784514

PIN code 784514 belongs to Darrang, Assam. It is used by 7 post offices: Lalpul Bazar, Aminpara, Bechimari, Daipam and others. Every one of them delivers post to homes.

What the digits of 784514 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 78: the first two digits together name the sub-zone, here the Assam Circle.
  • 784: the first three digits name the sorting district, where post for this area is sorted.
  • 514: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Darrang, Assam - 784514. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
