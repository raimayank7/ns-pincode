About PIN code 144523

PIN code 144523 belongs to Hoshiarpur, Punjab. It is used by 8 post offices: Binewal, Bhawanipur, Garhi Mansowal, Haibowal and others. Every one of them delivers post to homes.

What the digits of 144523 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 14: the first two digits together name the sub-zone, here the Punjab Circle.
  • 144: the first three digits name the sorting district, where post for this area is sorted.
  • 523: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Hoshiarpur, Punjab - 144523. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
