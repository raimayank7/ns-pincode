About PIN code 431702

PIN code 431702 belongs to Hingoli, Maharashtra. It is used by 19 post offices: Kalamnuri, Babhali, Dholkyachi Wadi, Gaul and others. Every one of them delivers post to homes.

What the digits of 431702 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 43: the first two digits together name the sub-zone, here the Maharashtra Circle.
  • 431: the first three digits name the sorting district, where post for this area is sorted.
  • 702: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Hingoli, Maharashtra - 431702. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
