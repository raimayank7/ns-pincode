About PIN code 793116

PIN code 793116 belongs to Ri Bhoi, Meghalaya. It is used by 4 post offices: Bhoilymbong, Raitong, Sohliya Iapngar, Umtngam. Every one of them delivers post to homes.

What the digits of 793116 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 79: the first two digits together name the sub-zone, here the North Eastern Circle.
  • 793: the first three digits name the sorting district, where post for this area is sorted.
  • 116: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ri Bhoi, Meghalaya - 793116. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
