About PIN code 248198

PIN code 248198 belongs to Dehradun, Uttarakhand. It is used by 3 post offices: Vikasnagar SO Dehradun, Pachhmiwala, WhtI. Every one of them delivers post to homes.

What the digits of 248198 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 24: the first two digits together name the sub-zone, here the Uttarakhand Circle.
  • 248: the first three digits name the sorting district, where post for this area is sorted.
  • 198: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Dehradun, Uttarakhand - 248198. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
