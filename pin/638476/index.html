About PIN code 638476

PIN code 638476 belongs to Erode, Tamil Nadu. It is used by 8 post offices: Gobichettipalayam South, Pudupalayam SO Erode, Kadukkampalayam, Kullampalayam and others. 7 offices deliver post to homes: Gobichettipalayam South, Kadukkampalayam, Kullampalayam, Nagadevampalayam, Nanjagoundenpalayam and others. The others only serve customers at the counter.

What the digits of 638476 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 63: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 638: the first three digits name the sorting district, where post for this area is sorted.
  • 476: the last three digits name the delivery post office within that sorting district.

Writing this address
