About PIN code 249193

PIN code 249193 belongs to Uttar Kashi, Uttarakhand. It is used by 21 post offices: Gyansu, Joshiyara, Uttarkashi, Uttarkashi Collectorate and others. 18 offices deliver post to homes: Uttarkashi, Bhankoli, Bharangaon, Bonga, Boun and others. The others only serve customers at the counter.

What the digits of 249193 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 24: the first two digits together name the sub-zone, here the Uttarakhand Circle.
  • 249: the first three digits name the sorting district, where post for this area is sorted.
  • 193: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Uttar Kashi, Uttarakhand - 249193. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
