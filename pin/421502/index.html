About PIN code 421502

PIN code 421502 belongs to Thane, Maharashtra. It is used by 1 post office (O.E.Ambernath). It delivers post to homes.

What the digits of 421502 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 42: the first two digits together name the sub-zone, here the Maharashtra Circle.
  • 421: the first three digits name the sorting district, where post for this area is sorted.
  • 502: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Thane, Maharashtra - 421502. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
