About PIN code 600023

PIN code 600023 belongs to Chennai, Tamil Nadu. It is used by 1 post office (Aynavaram). It delivers post to homes.

What the digits of 600023 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 60: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 600: the first three digits name the sorting district, where post for this area is sorted.
  • 023: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Chennai, Tamil Nadu - 600023. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
