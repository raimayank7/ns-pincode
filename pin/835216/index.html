About PIN code 835216

PIN code 835216 belongs to West Singhbhum, Jharkhand. It is used by 47 post offices: Murhu, Anridih, Bamhani, Bandgaon and others. Every one of them delivers post to homes.

What the digits of 835216 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 83: the first two digits together name the sub-zone, here the Jharkhand Circle.
  • 835: the first three digits name the sorting district, where post for this area is sorted.
  • 216: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: West Singhbhum, Jharkhand - 835216. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
