About PIN code 484440

PIN code 484440 belongs to Anuppur, Madhya Pradesh. It is used by 8 post offices: Bijuri, Baherabandh, Baitola, Bijuri Colliery and others. Every one of them delivers post to homes.

What the digits of 484440 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 48: the first two digits together name the sub-zone, here the Madhya Pradesh Circle.
  • 484: the first three digits name the sorting district, where post for this area is sorted.
  • 440: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Anuppur, Madhya Pradesh - 484440. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
