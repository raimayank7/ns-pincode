About PIN code 814146

PIN code 814146 belongs to Deoghar, Jharkhand. It is used by 30 post offices: Palojori, Ajnaridudhani, Asna, Baijnathpur and others. Every one of them delivers post to homes.

What the digits of 814146 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 81: the first two digits together name the sub-zone, here the Jharkhand Circle.
  • 814: the first three digits name the sorting district, where post for this area is sorted.
  • 146: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Deoghar, Jharkhand - 814146. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
