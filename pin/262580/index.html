About PIN code 262580

PIN code 262580 belongs to Champawat, Uttarakhand. It is used by 5 post offices: Devidhura, Dholigaon, Gagar, Rithakhal and others. Every one of them delivers post to homes.

What the digits of 262580 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 26: the first two digits together name the sub-zone, here the Uttarakhand Circle.
  • 262: the first three digits name the sorting district, where post for this area is sorted.
  • 580: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Champawat, Uttarakhand - 262580. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
