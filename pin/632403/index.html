About PIN code 632403

PIN code 632403 belongs to Ranipet, Tamil Nadu. It is used by 1 post office (Ranipet Industrial Estate). It delivers post to homes.

What the digits of 632403 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 63: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 632: the first three digits name the sorting district, where post for this area is sorted.
  • 403: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ranipet, Tamil Nadu - 632403. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
