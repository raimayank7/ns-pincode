About PIN code 506105

PIN code 506105 belongs to Mahabubabad, Telangana. It is used by 15 post offices: Kuravi, Ayyagaripalli, Bethole, Chintapalli and others. Every one of them delivers post to homes.

What the digits of 506105 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 50: the first two digits together name the sub-zone, here the Telangana Circle.
  • 506: the first three digits name the sorting district, where post for this area is sorted.
  • 105: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Mahabubabad, Telangana - 506105. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
