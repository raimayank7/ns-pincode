About PIN code 572132

PIN code 572132 belongs to Tumakuru, Karnataka. It is used by 16 post offices: Madhugiri, P. W. D. Colony (Madhugiri), R M Yard Madhugiri, Bijawara and others. 14 offices deliver post to homes: Madhugiri, Bijawara, Chinakavajra, Doddaveeragondanahalli, Ganjalagunte and others. The others only serve customers at the counter.

What the digits of 572132 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 57: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 572: the first three digits name the sorting district, where post for this area is sorted.
  • 132: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Tumakuru, Karnataka - 572132. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
