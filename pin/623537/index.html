About PIN code 623537

PIN code 623537 belongs to Ramanathapuram, Tamil Nadu. It is used by 4 post offices: Pottagavayal, Naranamangalam, PKodikulam, Sholandur. Every one of them delivers post to homes.

What the digits of 623537 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 62: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 623: the first three digits name the sorting district, where post for this area is sorted.
  • 537: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ramanathapuram, Tamil Nadu - 623537. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
