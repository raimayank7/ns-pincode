About PIN code 307514

PIN code 307514 belongs to Sirohi, Rajasthan. It is used by 11 post offices: Reodar, Basan, Bhatana, Bherugarh and others. Every one of them delivers post to homes.

What the digits of 307514 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 30: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 307: the first three digits name the sorting district, where post for this area is sorted.
  • 514: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Sirohi, Rajasthan - 307514. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
