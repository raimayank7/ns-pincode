About PIN code 534451

PIN code 534451 belongs to Eluru, Andhra Pradesh. It is used by 8 post offices: Lakkavaram S.O (West Godavari), Borrampalem, Ch.Pothepalli, Devulapalli and others. Every one of them delivers post to homes.

What the digits of 534451 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 53: the first two digits together name the sub-zone, here the Andhra Pradesh Circle.
  • 534: the first three digits name the sorting district, where post for this area is sorted.
  • 451: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Eluru, Andhra Pradesh - 534451. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
