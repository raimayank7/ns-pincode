About PIN code 303305

PIN code 303305 belongs to Jaipur, Rajasthan. It is used by 11 post offices: Banskho, Badwa, Dharampura, Dhula and others. Every one of them delivers post to homes.

What the digits of 303305 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 30: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 303: the first three digits name the sorting district, where post for this area is sorted.
  • 305: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Jaipur, Rajasthan - 303305. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
