About PIN code 263136

PIN code 263136 belongs to Nainital, Uttarakhand. It is used by 15 post offices: Bhimtal, Babiyar, Banana, Chanfi and others. Every one of them delivers post to homes.

What the digits of 263136 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 26: the first two digits together name the sub-zone, here the Uttarakhand Circle.
  • 263: the first three digits name the sorting district, where post for this area is sorted.
  • 136: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nainital, Uttarakhand - 263136. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
