About PIN code 632101

PIN code 632101 belongs to Vellore, Tamil Nadu. It is used by 11 post offices: Anaikattu, Alleri, Appukkal, Eripudur and others. Every one of them delivers post to homes.

What the digits of 632101 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 63: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 632: the first three digits name the sorting district, where post for this area is sorted.
  • 101: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Vellore, Tamil Nadu - 632101. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
