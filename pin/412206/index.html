About PIN code 412206

PIN code 412206 belongs to Pune, Maharashtra. It is used by 39 post offices: Bhor, Ambade, Ambavade, Ambeghar and others. Every one of them delivers post to homes.

What the digits of 412206 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 41: the first two digits together name the sub-zone, here the Maharashtra Circle.
  • 412: the first three digits name the sorting district, where post for this area is sorted.
  • 206: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Pune, Maharashtra - 412206. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
