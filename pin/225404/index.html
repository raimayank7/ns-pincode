About PIN code 225404

PIN code 225404 belongs to Barabanki, Uttar Pradesh. It is used by 4 post offices: Dariyabad RS, Neoli Danapur, Pahroopur, Patulki. Every one of them delivers post to homes.

What the digits of 225404 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 22: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 225: the first three digits name the sorting district, where post for this area is sorted.
  • 404: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Barabanki, Uttar Pradesh - 225404. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
