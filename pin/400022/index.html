About PIN code 400022

PIN code 400022 belongs to Mumbai, Maharashtra. It is used by 4 post offices: Chunabhatti, Raoli Camp, Sion, Transit Camp. 1 office delivers post to homes: Sion. The others only serve customers at the counter.

What the digits of 400022 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 40: the first two digits together name the sub-zone, here the Maharashtra Circle.
  • 400: the first three digits name the sorting district, where post for this area is sorted.
  • 022: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Mumbai, Maharashtra - 400022. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
