About PIN code 788104

PIN code 788104 belongs to Cachar, Assam. It is used by 2 post offices: Jirighat, Uttar Lalpani. Every one of them delivers post to homes.

What the digits of 788104 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 78: the first two digits together name the sub-zone, here the Assam Circle.
  • 788: the first three digits name the sorting district, where post for this area is sorted.
  • 104: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Cachar, Assam - 788104. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
