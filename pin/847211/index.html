About PIN code 847211

PIN code 847211 belongs to Madhubani, Bihar. It is used by 2 post offices: Madhubani, Madhubani Court. 1 office delivers post to homes: Madhubani. The others only serve customers at the counter.

What the digits of 847211 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 84: the first two digits together name the sub-zone, here the Bihar Circle.
  • 847: the first three digits name the sorting district, where post for this area is sorted.
  • 211: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Madhubani, Bihar - 847211. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
