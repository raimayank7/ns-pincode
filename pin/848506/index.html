About PIN code 848506

PIN code 848506 belongs to Samastipur, Bihar. It is used by 9 post offices: Baghra SO Samastipur, Dharnipatti, Dumri Bindgama, Hardaspur Diara and others. Every one of them delivers post to homes.

What the digits of 848506 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 84: the first two digits together name the sub-zone, here the Bihar Circle.
  • 848: the first three digits name the sorting district, where post for this area is sorted.
  • 506: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Samastipur, Bihar - 848506. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
