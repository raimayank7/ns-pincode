About PIN code 733126

PIN code 733126 belongs to Dinajpur Dakshin, West Bengal. It is used by 4 post offices: Hili, Fatepur, Hili Aftair, Trimohini. 3 offices deliver post to homes: Hili, Fatepur, Trimohini. The others only serve customers at the counter.

What the digits of 733126 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 73: the first two digits together name the sub-zone, here the West Bengal Circle.
  • 733: the first three digits name the sorting district, where post for this area is sorted.
  • 126: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Dinajpur Dakshin, West Bengal - 733126. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
