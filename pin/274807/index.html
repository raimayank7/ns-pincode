About PIN code 274807

PIN code 274807 belongs to Deoria, Uttar Pradesh. It is used by 18 post offices: SANT VINOBA MARG, Babhani, Bairauna, Barhara and others. Every one of them delivers post to homes.

What the digits of 274807 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 27: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 274: the first three digits name the sorting district, where post for this area is sorted.
  • 807: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Deoria, Uttar Pradesh - 274807. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
