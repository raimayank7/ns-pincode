About PIN code 335523

PIN code 335523 belongs to Hanumangarh, Rajasthan. It is used by 38 post offices: Nohar, Nohar Bazar, 6 Rpm, Aradhki and others. 37 offices deliver post to homes: Nohar, 6 Rpm, Aradhki, Balasar, Bhawal Desar and others. The others only serve customers at the counter.

What the digits of 335523 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 33: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 335: the first three digits name the sorting district, where post for this area is sorted.
  • 523: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Hanumangarh, Rajasthan - 335523. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
