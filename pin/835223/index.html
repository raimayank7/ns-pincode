About PIN code 835223

PIN code 835223 belongs to Simdega, Jharkhand. It is used by 23 post offices: Simdega, Bagdega, Basain, Bombalkera and others. Every one of them delivers post to homes.

What the digits of 835223 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 83: the first two digits together name the sub-zone, here the Jharkhand Circle.
  • 835: the first three digits name the sorting district, where post for this area is sorted.
  • 223: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Simdega, Jharkhand - 835223. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
