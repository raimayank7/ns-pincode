About PIN code 142030

PIN code 142030 belongs to Ludhiana, Punjab. It is used by 8 post offices: Kamalpura, Chachrari, Chajjewal, Cheema and others. Every one of them delivers post to homes.

What the digits of 142030 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 14: the first two digits together name the sub-zone, here the Punjab Circle.
  • 142: the first three digits name the sorting district, where post for this area is sorted.
  • 030: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ludhiana, Punjab - 142030. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
