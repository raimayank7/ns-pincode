About PIN code 400607

PIN code 400607 belongs to Thane, Maharashtra. It is used by 1 post office (Sandozbaugh). It delivers post to homes.

What the digits of 400607 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 40: the first two digits together name the sub-zone, here the Maharashtra Circle.
  • 400: the first three digits name the sorting district, where post for this area is sorted.
  • 607: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Thane, Maharashtra - 400607. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
