About PIN code 835224

PIN code 835224 belongs to Gumla, Jharkhand. It is used by 24 post offices: Sisai SO Gumla, Arko, Bargaon, Bhurso and others. Every one of them delivers post to homes.

What the digits of 835224 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 83: the first two digits together name the sub-zone, here the Jharkhand Circle.
  • 835: the first three digits name the sorting district, where post for this area is sorted.
  • 224: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Gumla, Jharkhand - 835224. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
