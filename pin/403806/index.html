About PIN code 403806

PIN code 403806 belongs to South Goa, Goa. It is used by 1 post office (Bogmalo). It delivers post to homes.

What the digits of 403806 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 40: the first two digits together name the sub-zone, here the Maharashtra Circle.
  • 403: the first three digits name the sorting district, where post for this area is sorted.
  • 806: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: South Goa, Goa - 403806. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
