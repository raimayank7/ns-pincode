About PIN code 263127

PIN code 263127 belongs to Nainital, Uttarakhand. It is used by 4 post offices: Jeolikote, Bist Estatre, Chopra, Gethia. Every one of them delivers post to homes.

What the digits of 263127 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 26: the first two digits together name the sub-zone, here the Uttarakhand Circle.
  • 263: the first three digits name the sorting district, where post for this area is sorted.
  • 127: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nainital, Uttarakhand - 263127. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
