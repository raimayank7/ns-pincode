About PIN code 494001

PIN code 494001 belongs to Raipur, Chhattisgarh. It is used by 65 post offices: Jagdalpur, Dharampura, Jagdalpur Kutchery, Jagdalpur Rly Colony and others. 58 offices deliver post to homes: Jagdalpur, Adawal, Amaguda, Babusemra, Bademorathpal and others. The others only serve customers at the counter.

What the digits of 494001 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 49: the first two digits together name the sub-zone, here the Chattisgarh Circle.
  • 494: the first three digits name the sorting district, where post for this area is sorted.
  • 001: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Raipur, Chhattisgarh - 494001. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
