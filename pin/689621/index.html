About PIN code 689621

PIN code 689621 belongs to Pathanamthitta, Kerala. It is used by 5 post offices: Niranam, Kadapra Mannar, Kizhakkumbhagom, Niranam Central and others. Every one of them delivers post to homes.

What the digits of 689621 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 68: the first two digits together name the sub-zone, here the Kerala Circle.
  • 689: the first three digits name the sorting district, where post for this area is sorted.
  • 621: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Pathanamthitta, Kerala - 689621. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
