About PIN code 828103

PIN code 828103 belongs to Dhanbad, Jharkhand. It is used by 1 post office (Bhelatand). It delivers post to homes.

What the digits of 828103 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 82: the first two digits together name the sub-zone, here the Jharkhand Circle.
  • 828: the first three digits name the sorting district, where post for this area is sorted.
  • 103: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Dhanbad, Jharkhand - 828103. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
