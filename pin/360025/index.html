About PIN code 360025

PIN code 360025 belongs to Rajkot, Gujarat. It is used by 14 post offices: Sardhar, Bedla, Bhandaria, Bhupgadh and others. Every one of them delivers post to homes.

What the digits of 360025 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 36: the first two digits together name the sub-zone, here the Gujarat Circle.
  • 360: the first three digits name the sorting district, where post for this area is sorted.
  • 025: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Rajkot, Gujarat - 360025. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
