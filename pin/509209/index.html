About PIN code 509209

PIN code 509209 belongs to Nagarkurnool, Telangana. It is used by 15 post offices: Nagarkurnool, Aitol, Chadubatla, Guntakodur and others. Every one of them delivers post to homes.

What the digits of 509209 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 50: the first two digits together name the sub-zone, here the Telangana Circle.
  • 509: the first three digits name the sorting district, where post for this area is sorted.
  • 209: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nagarkurnool, Telangana - 509209. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
