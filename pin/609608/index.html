About PIN code 609608

PIN code 609608 belongs to Thiruvarur, Tamil Nadu. It is used by 4 post offices: Kollapuram, Kurungulam, Menangudi, Ubayavedanthapuram. Every one of them delivers post to homes.

What the digits of 609608 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 60: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 609: the first three digits name the sorting district, where post for this area is sorted.
  • 608: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Thiruvarur, Tamil Nadu - 609608. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
