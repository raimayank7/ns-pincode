About PIN code 635122

PIN code 635122 belongs to Krishnagiri, Tamil Nadu. It is used by 8 post offices: Alapatti, Agaram Ittikkal, Bellarampalli, Doddapoovathi and others. Every one of them delivers post to homes.

What the digits of 635122 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 63: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 635: the first three digits name the sorting district, where post for this area is sorted.
  • 122: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Krishnagiri, Tamil Nadu - 635122. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
