About PIN code 244242

PIN code 244242 belongs to Amroha, Uttar Pradesh. It is used by 11 post offices: Ujhari, Bijnaura, Chakooni, Dehpa and others. Every one of them delivers post to homes.

What the digits of 244242 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 24: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 244: the first three digits name the sorting district, where post for this area is sorted.
  • 242: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Amroha, Uttar Pradesh - 244242. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
