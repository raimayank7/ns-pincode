About PIN code 625701

PIN code 625701 belongs to Madurai, Tamil Nadu. It is used by 8 post offices: Kalligudi, Avalsurampatti, KSennampatti, Kuraiyur and others. Every one of them delivers post to homes.

What the digits of 625701 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 62: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 625: the first three digits name the sorting district, where post for this area is sorted.
  • 701: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Madurai, Tamil Nadu - 625701. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
