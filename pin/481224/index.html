About PIN code 481224

PIN code 481224 belongs to Balaghat, Madhya Pradesh. It is used by 15 post offices: Karanja S.O (Balaghat), AMEDA, BADGAON, BAPDI and others. Every one of them delivers post to homes.

What the digits of 481224 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 48: the first two digits together name the sub-zone, here the Madhya Pradesh Circle.
  • 481: the first three digits name the sorting district, where post for this area is sorted.
  • 224: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Balaghat, Madhya Pradesh - 481224. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
