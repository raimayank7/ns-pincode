About PIN code 781126

PIN code 781126 belongs to Nalbari, Assam. It is used by 13 post offices: Mukalmua, Adabari, Balikuchi, Bhangnamari and others. Every one of them delivers post to homes.

What the digits of 781126 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 78: the first two digits together name the sub-zone, here the Assam Circle.
  • 781: the first three digits name the sorting district, where post for this area is sorted.
  • 126: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nalbari, Assam - 781126. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
