About PIN code 605109

PIN code 605109 belongs to Villupuram, Tamil Nadu. It is used by 6 post offices: Vanur, Katrampakkam, Olundiyapattu, Pulichapallam and others. Every one of them delivers post to homes.

What the digits of 605109 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 60: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 605: the first three digits name the sorting district, where post for this area is sorted.
  • 109: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Villupuram, Tamil Nadu - 605109. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
