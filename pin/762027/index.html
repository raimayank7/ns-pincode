About PIN code 762027

PIN code 762027 belongs to Kandhamal, Odisha. It is used by 5 post offices: Linepada, Bapalamendi, Dankuni, Jhagadapata and others. Every one of them delivers post to homes.

What the digits of 762027 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 76: the first two digits together name the sub-zone, here the Odisha Circle.
  • 762: the first three digits name the sorting district, where post for this area is sorted.
  • 027: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kandhamal, Odisha - 762027. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
