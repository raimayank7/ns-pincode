About PIN code 800016

PIN code 800016 belongs to Patna, Bihar. It is used by 1 post office (Rajendra Nagar SO Patna). It delivers post to homes.

What the digits of 800016 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 80: the first two digits together name the sub-zone, here the Bihar Circle.
  • 800: the first three digits name the sorting district, where post for this area is sorted.
  • 016: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Patna, Bihar - 800016. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
