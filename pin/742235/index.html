About PIN code 742235

PIN code 742235 belongs to Murshidabad, West Bengal. It is used by 8 post offices: Barala, Dakshingramsabitri, Ghorshala, Jarur and others. Every one of them delivers post to homes.

What the digits of 742235 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 74: the first two digits together name the sub-zone, here the West Bengal Circle.
  • 742: the first three digits name the sorting district, where post for this area is sorted.
  • 235: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Murshidabad, West Bengal - 742235. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
