About PIN code 560048

PIN code 560048 belongs to Bengaluru Urban, Karnataka. It is used by 2 post offices: Mahadevapura, Hoodi. 1 office delivers post to homes: Mahadevapura. The others only serve customers at the counter.

What the digits of 560048 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 56: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 560: the first three digits name the sorting district, where post for this area is sorted.
  • 048: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Bengaluru Urban, Karnataka - 560048. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
