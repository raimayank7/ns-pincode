About PIN code 602003

PIN code 602003 belongs to Thiruvallur, Tamil Nadu. It is used by 1 post office (Kakalur Ind Estate). It delivers post to homes.

What the digits of 602003 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 60: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 602: the first three digits name the sorting district, where post for this area is sorted.
  • 003: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Thiruvallur, Tamil Nadu - 602003. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
