About PIN code 502286

PIN code 502286 belongs to Sangareddy, Telangana. It is used by 27 post offices: Narayankhed, Abbenda, Ananthasagar, Audatpur and others. Every one of them delivers post to homes.

What the digits of 502286 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 50: the first two digits together name the sub-zone, here the Telangana Circle.
  • 502: the first three digits name the sorting district, where post for this area is sorted.
  • 286: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Sangareddy, Telangana - 502286. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
