About PIN code 613101

PIN code 613101 belongs to Thanjavur, Tamil Nadu. It is used by 7 post offices: Nadukaveri, Aimbadumelnagaram, Allur, Konerirajapuram and others. Every one of them delivers post to homes.

What the digits of 613101 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 61: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 613: the first three digits name the sorting district, where post for this area is sorted.
  • 101: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Thanjavur, Tamil Nadu - 613101. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
