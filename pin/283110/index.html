About PIN code 283110

PIN code 283110 belongs to Agra, Uttar Pradesh. It is used by 21 post offices: Fatehpur Sikri, Arhera, Aulanda, Baseri Kazi and others. Every one of them delivers post to homes.

What the digits of 283110 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 28: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 283: the first three digits name the sorting district, where post for this area is sorted.
  • 110: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Agra, Uttar Pradesh - 283110. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
