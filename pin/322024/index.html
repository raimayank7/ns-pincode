About PIN code 322024

PIN code 322024 belongs to Sawai Madhopur, Rajasthan. It is used by 9 post offices: Khirni, Bhadoti, Didwadi, Gambhira and others. Every one of them delivers post to homes.

What the digits of 322024 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 32: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 322: the first three digits name the sorting district, where post for this area is sorted.
  • 024: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Sawai Madhopur, Rajasthan - 322024. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
