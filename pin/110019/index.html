About PIN code 110019

PIN code 110019 belongs to South East, Delhi. It is used by 4 post offices: Kalkaji, Alaknanda, Chittranjan Park, Nehru Place. 1 office delivers post to homes: Kalkaji. The others only serve customers at the counter.

What the digits of 110019 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 11: the first two digits together name the sub-zone, here the Delhi Circle.
  • 110: the first three digits name the sorting district, where post for this area is sorted.
  • 019: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: South East, Delhi - 110019. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
