About PIN code 624001

PIN code 624001 belongs to Dindigul, Tamil Nadu. It is used by 4 post offices: Dindigul, Angunagar, Dindigul Fort, Pandianagar. 1 office delivers post to homes: Dindigul. The others only serve customers at the counter.

What the digits of 624001 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 62: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 624: the first three digits name the sorting district, where post for this area is sorted.
  • 001: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Dindigul, Tamil Nadu - 624001. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
