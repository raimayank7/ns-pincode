About PIN code 360110

PIN code 360110 belongs to Rajkot, Gujarat. It is used by 27 post offices: Paddhari, Adbalka, Dungarka, Hadmatiya and others. Every one of them delivers post to homes.

What the digits of 360110 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 36: the first two digits together name the sub-zone, here the Gujarat Circle.
  • 360: the first three digits name the sorting district, where post for this area is sorted.
  • 110: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Rajkot, Gujarat - 360110. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
