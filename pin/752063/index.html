About PIN code 752063

PIN code 752063 belongs to Nayagarh, Odisha. It is used by 17 post offices: Bhapur S.O (Nayagarh), Badasahara, Baunsabati, Bijipur and others. Every one of them delivers post to homes.

What the digits of 752063 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 75: the first two digits together name the sub-zone, here the Odisha Circle.
  • 752: the first three digits name the sorting district, where post for this area is sorted.
  • 063: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nayagarh, Odisha - 752063. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
