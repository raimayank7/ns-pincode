About PIN code 531151

PIN code 531151 belongs to Visakhapatanam, Andhra Pradesh. It is used by 24 post offices: Araku Rs, Araku, Arma, Dumbriguda and others. Every one of them delivers post to homes.

What the digits of 531151 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 53: the first two digits together name the sub-zone, here the Andhra Pradesh Circle.
  • 531: the first three digits name the sorting district, where post for this area is sorted.
  • 151: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Visakhapatanam, Andhra Pradesh - 531151. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
