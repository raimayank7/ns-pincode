About PIN code 712311

PIN code 712311 belongs to Hooghly, West Bengal. It is used by 4 post offices: DANKUNI HOUSING COMPLEX, Dankuni, Garalgacha, Mrigala. 3 offices deliver post to homes: Dankuni, Garalgacha, Mrigala. The others only serve customers at the counter.

What the digits of 712311 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 71: the first two digits together name the sub-zone, here the West Bengal Circle.
  • 712: the first three digits name the sorting district, where post for this area is sorted.
  • 311: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Hooghly, West Bengal - 712311. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
