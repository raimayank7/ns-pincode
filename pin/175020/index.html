About PIN code 175020

PIN code 175020 belongs to Mandi, Himachal Pradesh. It is used by 4 post offices: Gumma (Mandi), Harabagh, Jhatingri, Urla. Every one of them delivers post to homes.

What the digits of 175020 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 17: the first two digits together name the sub-zone, here the Himachal Pradesh Circle.
  • 175: the first three digits name the sorting district, where post for this area is sorted.
  • 020: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Mandi, Himachal Pradesh - 175020. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
