About PIN code 275201

PIN code 275201 belongs to Ghazipur, Uttar Pradesh. It is used by 5 post offices: Bahadurganj, Mahuwari, Pali, Ramgarh and others. Every one of them delivers post to homes.

What the digits of 275201 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 27: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 275: the first three digits name the sorting district, where post for this area is sorted.
  • 201: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ghazipur, Uttar Pradesh - 275201. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
