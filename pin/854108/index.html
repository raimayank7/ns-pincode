About PIN code 854108

PIN code 854108 belongs to Katihar, Bihar. It is used by 7 post offices: Korha, BHATWARA, DHANETHA, JHAGRUCHAK and others. Every one of them delivers post to homes.

What the digits of 854108 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 85: the first two digits together name the sub-zone, here the Bihar Circle.
  • 854: the first three digits name the sorting district, where post for this area is sorted.
  • 108: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Katihar, Bihar - 854108. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
