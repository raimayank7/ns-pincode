About PIN code 456006

PIN code 456006 belongs to Ujjain, Madhya Pradesh. It is used by 23 post offices: UJJAIN NAYAPURA, UJJAIN RAMGHATMARG, Ujjain City, Ujjain Gujrati Samaj and others. 19 offices deliver post to homes: Ujjain City, Amodiya, Chintaman Jawasia, Jethal, Kagdikaradia and others. The others only serve customers at the counter.

What the digits of 456006 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 45: the first two digits together name the sub-zone, here the Madhya Pradesh Circle.
  • 456: the first three digits name the sorting district, where post for this area is sorted.
  • 006: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ujjain, Madhya Pradesh - 456006. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
