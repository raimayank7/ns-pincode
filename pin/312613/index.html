About PIN code 312613

PIN code 312613 belongs to Chittorgarh, Rajasthan. It is used by 5 post offices: Sawa, Chiksi, Kannoj, Nahargarh and others. Every one of them delivers post to homes.

What the digits of 312613 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 31: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 312: the first three digits name the sorting district, where post for this area is sorted.
  • 613: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Chittorgarh, Rajasthan - 312613. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
