About PIN code 441401

PIN code 441401 belongs to Nagpur, Maharashtra. It is used by 22 post offices: Kanhan Pipri, Ajni, Belda, Borda and others. 21 offices deliver post to homes: Kanhan Pipri, Ajni, Belda, Borda, Deolapar and others. The others only serve customers at the counter.

What the digits of 441401 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 44: the first two digits together name the sub-zone, here the Maharashtra Circle.
  • 441: the first three digits name the sorting district, where post for this area is sorted.
  • 401: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nagpur, Maharashtra - 441401. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
