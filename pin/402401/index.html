About PIN code 402401

PIN code 402401 belongs to Raigad, Maharashtra. It is used by 10 post offices: Janjira Murud, Agardanda, Kashid, Majgaon and others. Every one of them delivers post to homes.

What the digits of 402401 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 40: the first two digits together name the sub-zone, here the Maharashtra Circle.
  • 402: the first three digits name the sorting district, where post for this area is sorted.
  • 401: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Raigad, Maharashtra - 402401. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
