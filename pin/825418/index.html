About PIN code 825418

PIN code 825418 belongs to Koderma, Jharkhand. It is used by 18 post offices: Domchanch Bazar, Arkhango, BAGRIDIH, Bagro and others. Every one of them delivers post to homes.

What the digits of 825418 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 82: the first two digits together name the sub-zone, here the Jharkhand Circle.
  • 825: the first three digits name the sorting district, where post for this area is sorted.
  • 418: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Koderma, Jharkhand - 825418. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
