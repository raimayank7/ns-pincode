About PIN code 465674

PIN code 465674 belongs to Rajgarh, Madhya Pradesh. It is used by 26 post offices: Biaora, Aamliyahat, Ashapura, Baiheda and others. 25 offices deliver post to homes: Biaora, Aamliyahat, Ashapura, Baiheda, Bankpura and others. The others only serve customers at the counter.

What the digits of 465674 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 46: the first two digits together name the sub-zone, here the Madhya Pradesh Circle.
  • 465: the first three digits name the sorting district, where post for this area is sorted.
  • 674: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Rajgarh, Madhya Pradesh - 465674. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
