About PIN code 803213

PIN code 803213 belongs to Patna, Bihar. It is used by 18 post offices: Barh, Barh Court, Achuara, Andauli and others. 17 offices deliver post to homes: Barh, Achuara, Andauli, Atnama, Berhna and others. The others only serve customers at the counter.

What the digits of 803213 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 80: the first two digits together name the sub-zone, here the Bihar Circle.
  • 803: the first three digits name the sorting district, where post for this area is sorted.
  • 213: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Patna, Bihar - 803213. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
