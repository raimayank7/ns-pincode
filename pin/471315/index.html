About PIN code 471315

PIN code 471315 belongs to Chhatarpur, Madhya Pradesh. It is used by 10 post offices: Ishanagar, Achatta, Bandhikala, Behata and others. Every one of them delivers post to homes.

What the digits of 471315 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 47: the first two digits together name the sub-zone, here the Madhya Pradesh Circle.
  • 471: the first three digits name the sorting district, where post for this area is sorted.
  • 315: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Chhatarpur, Madhya Pradesh - 471315. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
