About PIN code 344011

PIN code 344011 belongs to Barmer, Rajasthan. It is used by 28 post offices: Bishala, Adarsh Basti, Asadi, Balewa and others. Every one of them delivers post to homes.

What the digits of 344011 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 34: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 344: the first three digits name the sorting district, where post for this area is sorted.
  • 011: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Barmer, Rajasthan - 344011. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
