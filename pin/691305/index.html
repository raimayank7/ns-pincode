About PIN code 691305

PIN code 691305 belongs to Kollam, Kerala. It is used by 1 post office (Punalur). It delivers post to homes.

What the digits of 691305 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 69: the first two digits together name the sub-zone, here the Kerala Circle.
  • 691: the first three digits name the sorting district, where post for this area is sorted.
  • 305: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kollam, Kerala - 691305. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
