About PIN code 851110

PIN code 851110 belongs to Begusarai, Bihar. It is used by 1 post office (Khamhar PO). It delivers post to homes.

What the digits of 851110 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 85: the first two digits together name the sub-zone, here the Bihar Circle.
  • 851: the first three digits name the sorting district, where post for this area is sorted.
  • 110: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Begusarai, Bihar - 851110. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
