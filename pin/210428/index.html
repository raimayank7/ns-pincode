About PIN code 210428

PIN code 210428 belongs to Hamirpur, Uttar Pradesh. It is used by 6 post offices: Majhagawan, Dhagwan, Jarakhar, Malehta and others. Every one of them delivers post to homes.

What the digits of 210428 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 21: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 210: the first three digits name the sorting district, where post for this area is sorted.
  • 428: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Hamirpur, Uttar Pradesh - 210428. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
