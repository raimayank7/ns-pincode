About PIN code 682036

PIN code 682036 belongs to Ernakulam, Kerala. It is used by 1 post office (Panampilly Nagar). It delivers post to homes.

What the digits of 682036 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 68: the first two digits together name the sub-zone, here the Kerala Circle.
  • 682: the first three digits name the sorting district, where post for this area is sorted.
  • 036: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ernakulam, Kerala - 682036. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
