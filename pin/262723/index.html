About PIN code 262723

PIN code 262723 belongs to Kheri, Uttar Pradesh. It is used by 13 post offices: Dhaurahara SO Kheri, Amethi, Baburi, Bajaha and others. Every one of them delivers post to homes.

What the digits of 262723 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 26: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 262: the first three digits name the sorting district, where post for this area is sorted.
  • 723: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kheri, Uttar Pradesh - 262723. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
