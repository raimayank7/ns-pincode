About PIN code 389220

PIN code 389220 belongs to Mahisagar, Gujarat. It is used by 9 post offices: Kothamba, Dharapur, Guneli, Hathivan and others. Every one of them delivers post to homes.

What the digits of 389220 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 38: the first two digits together name the sub-zone, here the Gujarat Circle.
  • 389: the first three digits name the sorting district, where post for this area is sorted.
  • 220: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Mahisagar, Gujarat - 389220. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
