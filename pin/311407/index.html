About PIN code 311407

PIN code 311407 belongs to Bhilwara, Rajasthan. It is used by 8 post offices: Phulia Kalan, Deoriya, Dohriya, Hukumpura and others. Every one of them delivers post to homes.

What the digits of 311407 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 31: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 311: the first three digits name the sorting district, where post for this area is sorted.
  • 407: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Bhilwara, Rajasthan - 311407. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
