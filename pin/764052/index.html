About PIN code 764052

PIN code 764052 belongs to Malkangiri, Odisha. It is used by 45 post offices: Chitrakonda, Andrapali, Anibirida, Arabeti and others. Every one of them delivers post to homes.

What the digits of 764052 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 76: the first two digits together name the sub-zone, here the Odisha Circle.
  • 764: the first three digits name the sorting district, where post for this area is sorted.
  • 052: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Malkangiri, Odisha - 764052. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
