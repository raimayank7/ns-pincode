About PIN code 392220

PIN code 392220 belongs to Bharuch, Gujarat. It is used by 13 post offices: Palej, Haldarva, Kamboli, Kisnad and others. Every one of them delivers post to homes.

What the digits of 392220 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 39: the first two digits together name the sub-zone, here the Gujarat Circle.
  • 392: the first three digits name the sorting district, where post for this area is sorted.
  • 220: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Bharuch, Gujarat - 392220. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
