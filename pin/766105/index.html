About PIN code 766105

PIN code 766105 belongs to Nuapada, Odisha. It is used by 34 post offices: Nawapara Tanwat, Amnara, Chulabhat, Darlimunda and others. Every one of them delivers post to homes.

What the digits of 766105 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 76: the first two digits together name the sub-zone, here the Odisha Circle.
  • 766: the first three digits name the sorting district, where post for this area is sorted.
  • 105: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nuapada, Odisha - 766105. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
