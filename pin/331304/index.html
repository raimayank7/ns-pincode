About PIN code 331304

PIN code 331304 belongs to Churu, Rajasthan. It is used by 33 post offices: Taranagar, Taranagar Bazar, Allayala, Anandsinghpura and others. 32 offices deliver post to homes: Taranagar, Allayala, Anandsinghpura, Bain, Banara and others. The others only serve customers at the counter.

What the digits of 331304 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 33: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 331: the first three digits name the sorting district, where post for this area is sorted.
  • 304: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Churu, Rajasthan - 331304. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
