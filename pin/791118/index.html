About PIN code 791118

PIN code 791118 belongs to Kurung Kumey, Arunachal Pradesh. It is used by 149 post offices: Palin, Amji, Arr Guha, Asupinja and others. Every one of them delivers post to homes.

What the digits of 791118 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 79: the first two digits together name the sub-zone, here the North Eastern Circle.
  • 791: the first three digits name the sorting district, where post for this area is sorted.
  • 118: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kurung Kumey, Arunachal Pradesh - 791118. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
