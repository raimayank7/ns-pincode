About PIN code 232103

PIN code 232103 belongs to Chandauli, Uttar Pradesh. It is used by 20 post offices: Chakia, Bentairi, Bhabhaura, Bhaisahi and others. Every one of them delivers post to homes.

What the digits of 232103 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 23: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 232: the first three digits name the sorting district, where post for this area is sorted.
  • 103: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Chandauli, Uttar Pradesh - 232103. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
