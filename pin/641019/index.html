About PIN code 641019

PIN code 641019 belongs to Coimbatore, Tamil Nadu. It is used by 3 post offices: Coimbatore Press Colony, Bilichi, Veerapandi Periyanaickenpalaya. Every one of them delivers post to homes.

What the digits of 641019 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 64: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 641: the first three digits name the sorting district, where post for this area is sorted.
  • 019: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Coimbatore, Tamil Nadu - 641019. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
