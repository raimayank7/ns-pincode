About PIN code 636704

PIN code 636704 belongs to Dharmapuri, Tamil Nadu. It is used by 7 post offices: Annasagaram, A.Gollahalli, Akkamanahalli, Kuppur and others. Every one of them delivers post to homes.

What the digits of 636704 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 63: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 636: the first three digits name the sorting district, where post for this area is sorted.
  • 704: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Dharmapuri, Tamil Nadu - 636704. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
