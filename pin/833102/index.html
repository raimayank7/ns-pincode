About PIN code 833102

PIN code 833102 belongs to West Singhbhum, Jharkhand. It is used by 47 post offices: Chakradharpur, Chakradharpur Bazar, Chakradharpur Colony, Asantalia and others. 45 offices deliver post to homes: Chakradharpur, Asantalia, Baihatu, Baipee, Barabamboo and others. The others only serve customers at the counter.

What the digits of 833102 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 83: the first two digits together name the sub-zone, here the Jharkhand Circle.
  • 833: the first three digits name the sorting district, where post for this area is sorted.
  • 102: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: West Singhbhum, Jharkhand - 833102. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
