About PIN code 331302

PIN code 331302 belongs to Churu, Rajasthan. It is used by 9 post offices: Sahwa, Bharang, Dhirwas, Kikrali Charnan and others. Every one of them delivers post to homes.

What the digits of 331302 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 33: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 331: the first three digits name the sorting district, where post for this area is sorted.
  • 302: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Churu, Rajasthan - 331302. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
