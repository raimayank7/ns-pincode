About PIN code 475671

PIN code 475671 belongs to Datia, Madhya Pradesh. It is used by 10 post offices: Unnao, Aser, Ikara, Kamad and others. Every one of them delivers post to homes.

What the digits of 475671 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 47: the first two digits together name the sub-zone, here the Madhya Pradesh Circle.
  • 475: the first three digits name the sorting district, where post for this area is sorted.
  • 671: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Datia, Madhya Pradesh - 475671. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
