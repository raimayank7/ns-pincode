About PIN code 587301

PIN code 587301 belongs to Bagalkot, Karnataka. It is used by 17 post offices: Jamkhandi, Jamkhandi Girishanagar, Algur, Chikpadasalagi and others. 16 offices deliver post to homes: Jamkhandi, Algur, Chikpadasalagi, Chingundi, Hirepadasalagi and others. The others only serve customers at the counter.

What the digits of 587301 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 58: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 587: the first three digits name the sorting district, where post for this area is sorted.
  • 301: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Bagalkot, Karnataka - 587301. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
