About PIN code 271871

PIN code 271871 belongs to Bahraich, Uttar Pradesh. It is used by 13 post offices: Payagpur, Ailo, Basanera, Dhauli and others. 12 offices deliver post to homes: Payagpur, Ailo, Basanera, Dhauli, Kashijot and others. The others only serve customers at the counter.

What the digits of 271871 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 27: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 271: the first three digits name the sorting district, where post for this area is sorted.
  • 871: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Bahraich, Uttar Pradesh - 271871. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
