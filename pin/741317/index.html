About PIN code 741317

PIN code 741317 belongs to Nadia, West Bengal. It is used by 3 post offices: Joania Bhaluka, Aluipara, Joania. Every one of them delivers post to homes.

What the digits of 741317 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 74: the first two digits together name the sub-zone, here the West Bengal Circle.
  • 741: the first three digits name the sorting district, where post for this area is sorted.
  • 317: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nadia, West Bengal - 741317. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
