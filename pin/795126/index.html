About PIN code 795126

PIN code 795126 belongs to Kangpokpi, Manipur. It is used by 14 post offices: Bishnupur S.O (Bishnupur), Dolang, Dolang Khunou, Khoijuman and others. Every one of them delivers post to homes.

What the digits of 795126 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 79: the first two digits together name the sub-zone, here the North Eastern Circle.
  • 795: the first three digits name the sorting district, where post for this area is sorted.
  • 126: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kangpokpi, Manipur - 795126. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
