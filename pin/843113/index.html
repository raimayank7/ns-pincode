About PIN code 843113

PIN code 843113 belongs to Muzaffarpur, Bihar. It is used by 15 post offices: Patahi SO Muzaffarpur, ABishanpur, Bhatauna, Bishundatpur and others. Every one of them delivers post to homes.

What the digits of 843113 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 84: the first two digits together name the sub-zone, here the Bihar Circle.
  • 843: the first three digits name the sorting district, where post for this area is sorted.
  • 113: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Muzaffarpur, Bihar - 843113. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
