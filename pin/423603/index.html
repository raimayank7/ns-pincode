About PIN code 423603

PIN code 423603 belongs to Ahmednagar, Maharashtra. It is used by 8 post offices: Shinganapur, Dahigaon Bolka, Godhegaon, Karanji Bk and others. Every one of them delivers post to homes.

What the digits of 423603 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 42: the first two digits together name the sub-zone, here the Maharashtra Circle.
  • 423: the first three digits name the sorting district, where post for this area is sorted.
  • 603: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ahmednagar, Maharashtra - 423603. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
