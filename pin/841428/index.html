About PIN code 841428

PIN code 841428 belongs to Gopalganj, Bihar. It is used by 24 post offices: Gopalganj, Gopalganj College, Amwa Nakchhed, Babubishunpur and others. 23 offices deliver post to homes: Gopalganj, Amwa Nakchhed, Babubishunpur, Baraiptti, Basdila and others. The others only serve customers at the counter.

What the digits of 841428 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 84: the first two digits together name the sub-zone, here the Bihar Circle.
  • 841: the first three digits name the sorting district, where post for this area is sorted.
  • 428: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Gopalganj, Bihar - 841428. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
