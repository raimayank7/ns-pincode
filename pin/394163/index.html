About PIN code 394163

PIN code 394163 belongs to Surat, Gujarat. It is used by 17 post offices: Godsamba, Amalsadi, Amba, Fali and others. Every one of them delivers post to homes.

What the digits of 394163 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 39: the first two digits together name the sub-zone, here the Gujarat Circle.
  • 394: the first three digits name the sorting district, where post for this area is sorted.
  • 163: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Surat, Gujarat - 394163. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
