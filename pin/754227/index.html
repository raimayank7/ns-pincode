About PIN code 754227

PIN code 754227 belongs to Kendrapara, Odisha. It is used by 7 post offices: Olavar, Bahmanda, Baruna, Chhadesh and others. Every one of them delivers post to homes.

What the digits of 754227 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 75: the first two digits together name the sub-zone, here the Odisha Circle.
  • 754: the first three digits name the sorting district, where post for this area is sorted.
  • 227: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kendrapara, Odisha - 754227. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
