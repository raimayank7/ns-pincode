About PIN code 131001

PIN code 131001 belongs to Sonipat, Haryana. It is used by 26 post offices: Sonipat, Atlas Cycle, Ganzbazar, Gohana Road SO Sonipat and others. 16 offices deliver post to homes: Sonipat, Barwasni, Bayanpur, Delhi Road, FAZILPUR and others. The others only serve customers at the counter.

What the digits of 131001 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 13: the first two digits together name the sub-zone, here the Haryana Circle.
  • 131: the first three digits name the sorting district, where post for this area is sorted.
  • 001: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Sonipat, Haryana - 131001. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
