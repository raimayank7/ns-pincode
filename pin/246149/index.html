About PIN code 246149

PIN code 246149 belongs to Pauri Garhwal, Uttarakhand. It is used by 17 post offices: Kotdwara, BEL, Kotdwara Railway Station, Amsaur and others. 15 offices deliver post to homes: Kotdwara, Amsaur, Balasaur, Devikhal, Jhandichaur and others. The others only serve customers at the counter.

What the digits of 246149 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 24: the first two digits together name the sub-zone, here the Uttarakhand Circle.
  • 246: the first three digits name the sorting district, where post for this area is sorted.
  • 149: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Pauri Garhwal, Uttarakhand - 246149. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
