About PIN code 325602

PIN code 325602 belongs to Kota, Rajasthan. It is used by 9 post offices: Kanwas, Anwan, Baluheda, Bansya hedi and others. Every one of them delivers post to homes.

What the digits of 325602 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 32: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 325: the first three digits name the sorting district, where post for this area is sorted.
  • 602: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kota, Rajasthan - 325602. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
