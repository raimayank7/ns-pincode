About PIN code 756003

PIN code 756003 belongs to Baleshwar, Odisha. It is used by 15 post offices: Barabati, Makalpur, Motiganj S.O (Baleswar), Sahid Park and others. 11 offices deliver post to homes: Motiganj S.O (Baleswar), Badasindhia, Bhimpura, Chasakhand, Dahapada and others. The others only serve customers at the counter.

What the digits of 756003 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 75: the first two digits together name the sub-zone, here the Odisha Circle.
  • 756: the first three digits name the sorting district, where post for this area is sorted.
  • 003: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Baleshwar, Odisha - 756003. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
