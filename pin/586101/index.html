About PIN code 586101

PIN code 586101 belongs to Vijayapura, Karnataka. It is used by 4 post offices: Vijayapura, Vijayapura Bazar, Vijayapura Jorapur Peth, Vijayapura Kutchery. 1 office delivers post to homes: Vijayapura. The others only serve customers at the counter.

What the digits of 586101 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 58: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 586: the first three digits name the sorting district, where post for this area is sorted.
  • 101: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Vijayapura, Karnataka - 586101. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
