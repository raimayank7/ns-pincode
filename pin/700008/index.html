About PIN code 700008

PIN code 700008 belongs to Kolkata, West Bengal. It is used by 1 post office (Barisha). It delivers post to homes.

What the digits of 700008 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 70: the first two digits together name the sub-zone, here the West Bengal Circle.
  • 700: the first three digits name the sorting district, where post for this area is sorted.
  • 008: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kolkata, West Bengal - 700008. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
