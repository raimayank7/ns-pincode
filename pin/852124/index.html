About PIN code 852124

PIN code 852124 belongs to Saharsa, Bihar. It is used by 20 post offices: Panchgachiya, Aran, Bara, Barhsher and others. Every one of them delivers post to homes.

What the digits of 852124 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 85: the first two digits together name the sub-zone, here the Bihar Circle.
  • 852: the first three digits name the sorting district, where post for this area is sorted.
  • 124: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Saharsa, Bihar - 852124. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
