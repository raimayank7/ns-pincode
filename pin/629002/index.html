About PIN code 629002

PIN code 629002 belongs to Kanniyakumari, Tamil Nadu. It is used by 4 post offices: Kottar, Maravankudiyiruppu, Edalakudy, Irulappapuram. 1 office delivers post to homes: Kottar. The others only serve customers at the counter.

What the digits of 629002 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 62: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 629: the first three digits name the sorting district, where post for this area is sorted.
  • 002: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kanniyakumari, Tamil Nadu - 629002. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
