About PIN code 144502

PIN code 144502 belongs to Jalandhar, Punjab. It is used by 7 post offices: Dosanjh Kalan, Dhandwar, Kot Grewal, Lehal and others. Every one of them delivers post to homes.

What the digits of 144502 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 14: the first two digits together name the sub-zone, here the Punjab Circle.
  • 144: the first three digits name the sorting district, where post for this area is sorted.
  • 502: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Jalandhar, Punjab - 144502. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
