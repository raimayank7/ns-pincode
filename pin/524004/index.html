About PIN code 524004

PIN code 524004 belongs to Spsr Nellore, Andhra Pradesh. It is used by 10 post offices: Andhrakesari Nagar, Vedayapalem, Buja Buja Nellore, Devarapalem and others. 9 offices deliver post to homes: Andhrakesari Nagar, Buja Buja Nellore, Devarapalem, Kommarapudi, Kondlapudi and others. The others only serve customers at the counter.

What the digits of 524004 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 52: the first two digits together name the sub-zone, here the Andhra Pradesh Circle.
  • 524: the first three digits name the sorting district, where post for this area is sorted.
  • 004: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Spsr Nellore, Andhra Pradesh - 524004. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
