About PIN code 233232

PIN code 233232 belongs to Ghazipur, Uttar Pradesh. It is used by 6 post offices: Goshandepur, Barsara, Dharammarpur, Dinapur and others. Every one of them delivers post to homes.

What the digits of 233232 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 23: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 233: the first three digits name the sorting district, where post for this area is sorted.
  • 232: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ghazipur, Uttar Pradesh - 233232. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
