About PIN code 277304

PIN code 277304 belongs to Ballia, Uttar Pradesh. It is used by 7 post offices: SUKHPURA, Apail, Beruarbari, Bharakhara and others. Every one of them delivers post to homes.

What the digits of 277304 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 27: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 277: the first three digits name the sorting district, where post for this area is sorted.
  • 304: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ballia, Uttar Pradesh - 277304. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
