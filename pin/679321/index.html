About PIN code 679321

PIN code 679321 belongs to Malappuram, Kerala. It is used by 9 post offices: Angadipuram, Aripra, Cherakkaparamba, Kadungapurm and others. Every one of them delivers post to homes.

What the digits of 679321 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 67: the first two digits together name the sub-zone, here the Kerala Circle.
  • 679: the first three digits name the sorting district, where post for this area is sorted.
  • 321: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Malappuram, Kerala - 679321. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
