About PIN code 732202

PIN code 732202 belongs to Maldah, West Bengal. It is used by 9 post offices: Manikchak, Chowki Mirdadpur, Dallutola, Dharampur and others. Every one of them delivers post to homes.

What the digits of 732202 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 73: the first two digits together name the sub-zone, here the West Bengal Circle.
  • 732: the first three digits name the sorting district, where post for this area is sorted.
  • 202: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Maldah, West Bengal - 732202. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
