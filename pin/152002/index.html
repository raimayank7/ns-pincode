About PIN code 152002

PIN code 152002 belongs to Firozepur, Punjab. It is used by 14 post offices: Chowk Arya Samaj Ferozepur, Ferozepur City, Industrial Area Ferozepur city, Bare Ke and others. 12 offices deliver post to homes: Ferozepur City, Bare Ke, Chak Haraj, Dod RS, Dulchike and others. The others only serve customers at the counter.

What the digits of 152002 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 15: the first two digits together name the sub-zone, here the Punjab Circle.
  • 152: the first three digits name the sorting district, where post for this area is sorted.
  • 002: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Firozepur, Punjab - 152002. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
