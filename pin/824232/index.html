About PIN code 824232

PIN code 824232 belongs to Gaya, Bihar. It is used by 32 post offices: Fatehpur SO Gaya, AROPUR, Akamba, Ambatari and others. Every one of them delivers post to homes.

What the digits of 824232 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 82: the first two digits together name the sub-zone, here the Bihar Circle.
  • 824: the first three digits name the sorting district, where post for this area is sorted.
  • 232: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Gaya, Bihar - 824232. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
