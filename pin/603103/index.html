About PIN code 603103

PIN code 603103 belongs to Chengalpattu, Tamil Nadu. It is used by 3 post offices: Kelambakkam, Padur, Pudupakkam. 2 offices deliver post to homes: Kelambakkam, Pudupakkam. The others only serve customers at the counter.

What the digits of 603103 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 60: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 603: the first three digits name the sorting district, where post for this area is sorted.
  • 103: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Chengalpattu, Tamil Nadu - 603103. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
