About PIN code 583117

PIN code 583117 belongs to Ballari, Karnataka. It is used by 13 post offices: Moka, Basarakodu, Belachinta, Bennikallu and others. Every one of them delivers post to homes.

What the digits of 583117 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 58: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 583: the first three digits name the sorting district, where post for this area is sorted.
  • 117: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ballari, Karnataka - 583117. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
