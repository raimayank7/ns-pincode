About PIN code 370230

PIN code 370230 belongs to Kachchh, Gujarat. It is used by 1 post office (Kandla Special Economic Zone). None of them is a delivery office: post for this PIN code is delivered by a nearby delivery office.

What the digits of 370230 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 37: the first two digits together name the sub-zone, here the Gujarat Circle.
  • 370: the first three digits name the sorting district, where post for this area is sorted.
  • 230: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kachchh, Gujarat - 370230. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
