About PIN code 380023

PIN code 380023 belongs to Ahmadabad, Gujarat. It is used by 2 post offices: Rakhial Udyog Vistar, Sukhrampura. 1 office delivers post to homes: Rakhial Udyog Vistar. The others only serve customers at the counter.

What the digits of 380023 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 38: the first two digits together name the sub-zone, here the Gujarat Circle.
  • 380: the first three digits name the sorting district, where post for this area is sorted.
  • 023: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ahmadabad, Gujarat - 380023. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
