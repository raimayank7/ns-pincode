About PIN code 722204

PIN code 722204 belongs to Bankura, West Bengal. It is used by 1 post office (Hatasuria). It delivers post to homes.

What the digits of 722204 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 72: the first two digits together name the sub-zone, here the West Bengal Circle.
  • 722: the first three digits name the sorting district, where post for this area is sorted.
  • 204: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Bankura, West Bengal - 722204. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
