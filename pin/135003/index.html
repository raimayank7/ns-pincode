About PIN code 135003

PIN code 135003 belongs to Yamunanagar, Haryana. It is used by 15 post offices: Jagadhri, Jagadhri Court, Jagadhri Town, Parkash Chowk and others. 11 offices deliver post to homes: Jagadhri, Balchhapar, Bherthal, Dadupur, Jroda and others. The others only serve customers at the counter.

What the digits of 135003 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 13: the first two digits together name the sub-zone, here the Haryana Circle.
  • 135: the first three digits name the sorting district, where post for this area is sorted.
  • 003: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Yamunanagar, Haryana - 135003. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
