About PIN code 243505

PIN code 243505 belongs to Bareilly, Uttar Pradesh. It is used by 17 post offices: Shahi, Bairamnagar, Balli, Dhaneli and others. Every one of them delivers post to homes.

What the digits of 243505 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 24: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 243: the first three digits name the sorting district, where post for this area is sorted.
  • 505: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Bareilly, Uttar Pradesh - 243505. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
