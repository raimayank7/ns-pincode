About PIN code 307001

PIN code 307001 belongs to Sirohi, Rajasthan. It is used by 16 post offices: Sirohi, Sirohi Bhatkra, Sirohi Sarupvilas, Balda and others. 14 offices deliver post to homes: Sirohi, Balda, Dhanta, Dodua, Gohili and others. The others only serve customers at the counter.

What the digits of 307001 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 30: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 307: the first three digits name the sorting district, where post for this area is sorted.
  • 001: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Sirohi, Rajasthan - 307001. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
