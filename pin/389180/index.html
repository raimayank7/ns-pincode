About PIN code 389180

PIN code 389180 belongs to Dohad, Gujarat. It is used by 25 post offices: Limdi, Amba, Bhadkhadabar, Bilwani and others. Every one of them delivers post to homes.

What the digits of 389180 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 38: the first two digits together name the sub-zone, here the Gujarat Circle.
  • 389: the first three digits name the sorting district, where post for this area is sorted.
  • 180: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Dohad, Gujarat - 389180. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
