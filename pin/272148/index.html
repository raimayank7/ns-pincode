About PIN code 272148

PIN code 272148 belongs to Basti, Uttar Pradesh. It is used by 12 post offices: Rayath, Chauri Khurd, Chiraiha, Dandwapandey and others. Every one of them delivers post to homes.

What the digits of 272148 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 27: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 272: the first three digits name the sorting district, where post for this area is sorted.
  • 148: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Basti, Uttar Pradesh - 272148. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
