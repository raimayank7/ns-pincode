About PIN code 751019

PIN code 751019 belongs to Khordha, Odisha. It is used by 7 post offices: Dumduma Housing Board Colony, Aiginia, Aiims Ndbo, Jadupur and others. 6 offices deliver post to homes: Dumduma Housing Board Colony, Aiginia, Jadupur, Kalinga Vihar, Patrapada and others. The others only serve customers at the counter.

What the digits of 751019 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 75: the first two digits together name the sub-zone, here the Odisha Circle.
  • 751: the first three digits name the sorting district, where post for this area is sorted.
  • 019: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Khordha, Odisha - 751019. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
