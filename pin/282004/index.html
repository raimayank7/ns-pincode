About PIN code 282004

PIN code 282004 belongs to Agra, Uttar Pradesh. It is used by 5 post offices: Agra University, GG Industries, JOHNS MILLS, KAMLA NAGAR and others. 1 office delivers post to homes: TAJ NAGRI. The others only serve customers at the counter.

What the digits of 282004 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 28: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 282: the first three digits name the sorting district, where post for this area is sorted.
  • 004: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Agra, Uttar Pradesh - 282004. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
