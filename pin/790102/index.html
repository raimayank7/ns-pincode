About PIN code 790102

PIN code 790102 belongs to East Kameng, Arunachal Pradesh. It is used by 98 post offices: Seppa, 18th Mile Camp, 40 K.M. Camp, Attarang and others. Every one of them delivers post to homes.

What the digits of 790102 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 79: the first two digits together name the sub-zone, here the North Eastern Circle.
  • 790: the first three digits name the sorting district, where post for this area is sorted.
  • 102: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: East Kameng, Arunachal Pradesh - 790102. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
