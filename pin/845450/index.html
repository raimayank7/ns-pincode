About PIN code 845450

PIN code 845450 belongs to Pashchim Champaran, Bihar. It is used by 11 post offices: Chuhari, Ashram Brindavan, Auraiya, Gurwalia and others. Every one of them delivers post to homes.

What the digits of 845450 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 84: the first two digits together name the sub-zone, here the Bihar Circle.
  • 845: the first three digits name the sorting district, where post for this area is sorted.
  • 450: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Pashchim Champaran, Bihar - 845450. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
