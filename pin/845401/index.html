About PIN code 845401

PIN code 845401 belongs to Purbi Champaran, Bihar. It is used by 20 post offices: Motihari, Chhatauni, Majharia, Motihari Chowk and others. 15 offices deliver post to homes: Motihari, Bariarpur, Chailaha, Dhekaha Bazar, Katha Loknathpur and others. The others only serve customers at the counter.

What the digits of 845401 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 84: the first two digits together name the sub-zone, here the Bihar Circle.
  • 845: the first three digits name the sorting district, where post for this area is sorted.
  • 401: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Purbi Champaran, Bihar - 845401. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
