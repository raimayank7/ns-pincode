About PIN code 496450

PIN code 496450 belongs to Raigarh, Chhattisgarh. It is used by 19 post offices: Hardi SO Raigarh, Badegantuli, Bhedwan, Bhothli and others. Every one of them delivers post to homes.

What the digits of 496450 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 49: the first two digits together name the sub-zone, here the Chattisgarh Circle.
  • 496: the first three digits name the sorting district, where post for this area is sorted.
  • 450: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Raigarh, Chhattisgarh - 496450. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
