About PIN code 577139

PIN code 577139 belongs to Chikkamagaluru, Karnataka. It is used by 18 post offices: Sringeri, Agalagandi, Darekoppa, Gandaghatta and others. 17 offices deliver post to homes: Sringeri, Agalagandi, Darekoppa, Gandaghatta, Halandur and others. The others only serve customers at the counter.

What the digits of 577139 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 57: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 577: the first three digits name the sorting district, where post for this area is sorted.
  • 139: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Chikkamagaluru, Karnataka - 577139. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
