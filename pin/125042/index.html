About PIN code 125042

PIN code 125042 belongs to Hisar, Haryana. It is used by 10 post offices: Bass, Badala, Badchhpar, Bhatol Jattan and others. Every one of them delivers post to homes.

What the digits of 125042 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 12: the first two digits together name the sub-zone, here the Haryana Circle.
  • 125: the first three digits name the sorting district, where post for this area is sorted.
  • 042: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Hisar, Haryana - 125042. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
