About PIN code 628617

PIN code 628617 belongs to Tuticorin, Tamil Nadu. It is used by 8 post offices: Nazareth, Chinnamadankudiyiruppu, Eluvaraimukki, Kurippankulam and others. 7 offices deliver post to homes: Nazareth, Chinnamadankudiyiruppu, Eluvaraimukki, Kurippankulam, Thailapuram and others. The others only serve customers at the counter.

What the digits of 628617 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 62: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 628: the first three digits name the sorting district, where post for this area is sorted.
  • 617: the last three digits name the delivery post office within that sorting district.

Writing this address
