About PIN code 332701

PIN code 332701 belongs to Sikar, Rajasthan. It is used by 12 post offices: Ajitgarh Amarsar, Ajmeri, Aspura, Deorala and others. Every one of them delivers post to homes.

What the digits of 332701 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 33: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 332: the first three digits name the sorting district, where post for this area is sorted.
  • 701: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Sikar, Rajasthan - 332701. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
