About PIN code 626201

PIN code 626201 belongs to Virudhunagar, Tamil Nadu. It is used by 4 post offices: Elayirampannai, Karisalpatti, Panayadipatti, Sankarapandiapuram. Every one of them delivers post to homes.

What the digits of 626201 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 62: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 626: the first three digits name the sorting district, where post for this area is sorted.
  • 201: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Virudhunagar, Tamil Nadu - 626201. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
