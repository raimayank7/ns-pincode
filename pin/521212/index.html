About PIN code 521212

PIN code 521212 belongs to Eluru, Andhra Pradesh. It is used by 5 post offices: Nunna, Adavinekkalam, Kanasanapalli, Pathapadu and others. Every one of them delivers post to homes.

What the digits of 521212 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 52: the first two digits together name the sub-zone, here the Andhra Pradesh Circle.
  • 521: the first three digits name the sorting district, where post for this area is sorted.
  • 212: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Eluru, Andhra Pradesh - 521212. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
