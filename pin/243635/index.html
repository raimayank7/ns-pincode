About PIN code 243635

PIN code 243635 belongs to Budaun, Uttar Pradesh. It is used by 26 post offices: Dataganj, Azampur Bisaria, Baksena, Bela Dandi and others. Every one of them delivers post to homes.

What the digits of 243635 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 24: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 243: the first three digits name the sorting district, where post for this area is sorted.
  • 635: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Budaun, Uttar Pradesh - 243635. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
