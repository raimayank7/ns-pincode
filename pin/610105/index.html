About PIN code 610105

PIN code 610105 belongs to Thiruvarur, Tamil Nadu. It is used by 10 post offices: Nannilam, Nannilam Cutchery, Achuthamangalam, Adambar and others. 8 offices deliver post to homes: Nannilam, Achuthamangalam, Adambar, Anaikuppam, Nemmeli and others. The others only serve customers at the counter.

What the digits of 610105 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 61: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 610: the first three digits name the sorting district, where post for this area is sorted.
  • 105: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Thiruvarur, Tamil Nadu - 610105. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
