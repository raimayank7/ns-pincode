About PIN code 560080

PIN code 560080 belongs to Bengaluru Urban, Karnataka. It is used by 1 post office (Sadashivanagar). It delivers post to homes.

What the digits of 560080 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 56: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 560: the first three digits name the sorting district, where post for this area is sorted.
  • 080: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Bengaluru Urban, Karnataka - 560080. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
