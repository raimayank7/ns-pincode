About PIN code 431804

PIN code 431804 belongs to Nanded, Maharashtra. It is used by 20 post offices: Kinwat, Ambadi, Digadi, Ghoti and others. Every one of them delivers post to homes.

What the digits of 431804 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 43: the first two digits together name the sub-zone, here the Maharashtra Circle.
  • 431: the first three digits name the sorting district, where post for this area is sorted.
  • 804: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nanded, Maharashtra - 431804. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
