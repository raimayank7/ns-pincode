About PIN code 211016

PIN code 211016 belongs to Prayagraj, Uttar Pradesh. It is used by 3 post offices: G T B Nagar, Kesaria Road, Purshottam Nagar. 1 office delivers post to homes: G T B Nagar. The others only serve customers at the counter.

What the digits of 211016 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 21: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 211: the first three digits name the sorting district, where post for this area is sorted.
  • 016: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Prayagraj, Uttar Pradesh - 211016. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
