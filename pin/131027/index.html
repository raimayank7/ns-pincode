About PIN code 131027

PIN code 131027 belongs to Sonipat, Haryana. It is used by 4 post offices: Murthal, Asadpur Nandnaur, Jainpur, Malikpur. Every one of them delivers post to homes.

What the digits of 131027 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 13: the first two digits together name the sub-zone, here the Haryana Circle.
  • 131: the first three digits name the sorting district, where post for this area is sorted.
  • 027: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Sonipat, Haryana - 131027. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
