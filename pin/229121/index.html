About PIN code 229121

PIN code 229121 belongs to Rae Bareli, Uttar Pradesh. It is used by 7 post offices: Aihar, Ataura Bujurg, Hasnapur, Kundwal and others. Every one of them delivers post to homes.

What the digits of 229121 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 22: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 229: the first three digits name the sorting district, where post for this area is sorted.
  • 121: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Rae Bareli, Uttar Pradesh - 229121. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
