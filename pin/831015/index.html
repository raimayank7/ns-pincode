About PIN code 831015

PIN code 831015 belongs to East Singhbum, Jharkhand. It is used by 1 post office (Gobindpur Housing Colony). It delivers post to homes.

What the digits of 831015 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 83: the first two digits together name the sub-zone, here the Jharkhand Circle.
  • 831: the first three digits name the sorting district, where post for this area is sorted.
  • 015: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: East Singhbum, Jharkhand - 831015. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
