About PIN code 246763

PIN code 246763 belongs to Bijnor, Uttar Pradesh. It is used by 26 post offices: I A Najibabad, Kallooganj, Najibabad, Najibabad RS and others. 22 offices deliver post to homes: Najibabad, Chandanpura, Dhansini, Fazalpur, Gaindi Khata and others. The others only serve customers at the counter.

What the digits of 246763 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 24: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 246: the first three digits name the sorting district, where post for this area is sorted.
  • 763: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Bijnor, Uttar Pradesh - 246763. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
