About PIN code 572175

PIN code 572175 belongs to Tumakuru, Karnataka. It is used by 8 post offices: Puravara, Badakanahalli, Byalya, Chikkamalur and others. Every one of them delivers post to homes.

What the digits of 572175 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 57: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 572: the first three digits name the sorting district, where post for this area is sorted.
  • 175: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Tumakuru, Karnataka - 572175. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
