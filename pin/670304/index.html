About PIN code 670304

PIN code 670304 belongs to Kannur, Kerala. It is used by 1 post office (Madayi). It delivers post to homes.

What the digits of 670304 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 67: the first two digits together name the sub-zone, here the Kerala Circle.
  • 670: the first three digits name the sorting district, where post for this area is sorted.
  • 304: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kannur, Kerala - 670304. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
