About PIN code 811309

PIN code 811309 belongs to Lakhisarai, Bihar. It is used by 7 post offices: Kajra, Arma, Lai, Pawai and others. Every one of them delivers post to homes.

What the digits of 811309 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 81: the first two digits together name the sub-zone, here the Bihar Circle.
  • 811: the first three digits name the sorting district, where post for this area is sorted.
  • 309: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Lakhisarai, Bihar - 811309. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
