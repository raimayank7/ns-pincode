About PIN code 531105

PIN code 531105 belongs to Alluri Sitharama Raju, Andhra Pradesh. It is used by 3 post offices: Sileru Project, Darakonda, Duppulavada. Every one of them delivers post to homes.

What the digits of 531105 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 53: the first two digits together name the sub-zone, here the Andhra Pradesh Circle.
  • 531: the first three digits name the sorting district, where post for this area is sorted.
  • 105: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Alluri Sitharama Raju, Andhra Pradesh - 531105. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
