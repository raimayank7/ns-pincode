About PIN code 781150

PIN code 781150 belongs to Kamrup Metro, Assam. It is used by 2 post offices: Chandrapur S.O (Kamrup), Gobardhan. 1 office delivers post to homes: Chandrapur S.O (Kamrup). The others only serve customers at the counter.

What the digits of 781150 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 78: the first two digits together name the sub-zone, here the Assam Circle.
  • 781: the first three digits name the sorting district, where post for this area is sorted.
  • 150: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kamrup Metro, Assam - 781150. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
