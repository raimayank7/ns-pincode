About PIN code 441203

PIN code 441203 belongs to Nagpur, Maharashtra. It is used by 19 post offices: Umred, Umred Bazar, Aptur, Bamhni and others. 18 offices deliver post to homes: Umred, Aptur, Bamhni, Bhagwanpur, Dawha and others. The others only serve customers at the counter.

What the digits of 441203 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 44: the first two digits together name the sub-zone, here the Maharashtra Circle.
  • 441: the first three digits name the sorting district, where post for this area is sorted.
  • 203: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nagpur, Maharashtra - 441203. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
