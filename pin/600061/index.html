About PIN code 600061

PIN code 600061 belongs to Chennai, Tamil Nadu. It is used by 2 post offices: Nanganallur, Pazhavanthangal. 1 office delivers post to homes: Nanganallur. The others only serve customers at the counter.

What the digits of 600061 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 60: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 600: the first three digits name the sorting district, where post for this area is sorted.
  • 061: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Chennai, Tamil Nadu - 600061. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
