About PIN code 151505

PIN code 151505 belongs to Mansa, Punjab. It is used by 19 post offices: Distt Couts Mansa, Mansa SO Mansa, Akkanwali, Bajjewala and others. 18 offices deliver post to homes: Mansa SO Mansa, Akkanwali, Bajjewala, Bhamme Kalan, Dulo Wal and others. The others only serve customers at the counter.

What the digits of 151505 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 15: the first two digits together name the sub-zone, here the Punjab Circle.
  • 151: the first three digits name the sorting district, where post for this area is sorted.
  • 505: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Mansa, Punjab - 151505. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
