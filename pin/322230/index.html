About PIN code 322230

PIN code 322230 belongs to Karauli, Rajasthan. It is used by 21 post offices: Hindaun, Hindaun City, Hindaun Mandi, Bajna Kalan and others. 19 offices deliver post to homes: Hindaun, Bajna Kalan, Bargama, Bhopar, Dahra and others. The others only serve customers at the counter.

What the digits of 322230 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 32: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 322: the first three digits name the sorting district, where post for this area is sorted.
  • 230: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Karauli, Rajasthan - 322230. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
