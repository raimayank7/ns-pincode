About PIN code 671326

PIN code 671326 belongs to Kasaragod, Kerala. It is used by 2 post offices: Chittarikkal, Mandapam. Every one of them delivers post to homes.

What the digits of 671326 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 67: the first two digits together name the sub-zone, here the Kerala Circle.
  • 671: the first three digits name the sorting district, where post for this area is sorted.
  • 326: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kasaragod, Kerala - 671326. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
