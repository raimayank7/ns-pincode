About PIN code 497225

PIN code 497225 belongs to Balrampur, Chhattisgarh. It is used by 34 post offices: Wadrafnagar, Balangi, Bamhani, Basantpur and others. Every one of them delivers post to homes.

What the digits of 497225 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 49: the first two digits together name the sub-zone, here the Chattisgarh Circle.
  • 497: the first three digits name the sorting district, where post for this area is sorted.
  • 225: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Balrampur, Chhattisgarh - 497225. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
