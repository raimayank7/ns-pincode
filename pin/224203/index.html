About PIN code 224203

PIN code 224203 belongs to Ayodhya, Uttar Pradesh. It is used by 9 post offices: Rampur Bhagan, Baraon, Beni Gaddopur, Kesharuabujurg and others. Every one of them delivers post to homes.

What the digits of 224203 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 22: the first two digits together name the sub-zone, here the Uttar Pradesh Circle.
  • 224: the first three digits name the sorting district, where post for this area is sorted.
  • 203: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Ayodhya, Uttar Pradesh - 224203. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
