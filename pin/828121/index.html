About PIN code 828121

PIN code 828121 belongs to Dhanbad, Jharkhand. It is used by 3 post offices: Sijua, Bhadrichak, Chandore. Every one of them delivers post to homes.

What the digits of 828121 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 82: the first two digits together name the sub-zone, here the Jharkhand Circle.
  • 828: the first three digits name the sorting district, where post for this area is sorted.
  • 121: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Dhanbad, Jharkhand - 828121. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
