About PIN code 263139

PIN code 263139 belongs to Nainital, Uttarakhand. It is used by 23 post offices: Haldwani, Bareilly Road, Bhotia Parao, Kaladhungi Road and others. 18 offices deliver post to homes: Haldwani, Anandpur, Arjunpur, Bari Mukhani, Chakalua and others. The others only serve customers at the counter.

What the digits of 263139 mean

  • 2: the postal zone, which covers Uttar Pradesh and Uttarakhand.
  • 26: the first two digits together name the sub-zone, here the Uttarakhand Circle.
  • 263: the first three digits name the sorting district, where post for this area is sorted.
  • 139: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nainital, Uttarakhand - 263139. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
