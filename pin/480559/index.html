About PIN code 480559

PIN code 480559 belongs to Chhindwara, Madhya Pradesh. It is used by 47 post offices: Tamia, Almod, Babai Pathar, Bamdi and others. Every one of them delivers post to homes.

What the digits of 480559 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 48: the first two digits together name the sub-zone, here the Madhya Pradesh Circle.
  • 480: the first three digits name the sorting district, where post for this area is sorted.
  • 559: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Chhindwara, Madhya Pradesh - 480559. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
