About PIN code 781102

PIN code 781102 belongs to Kamrup, Assam. It is used by 18 post offices: Hajo, Akadi, Bagta, Bhelkarbazar and others. Every one of them delivers post to homes.

What the digits of 781102 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 78: the first two digits together name the sub-zone, here the Assam Circle.
  • 781: the first three digits name the sorting district, where post for this area is sorted.
  • 102: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kamrup, Assam - 781102. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
