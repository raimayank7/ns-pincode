About PIN code 394641

PIN code 394641 belongs to Tapi, Gujarat. It is used by 3 post offices: Ambach, Gandhi Vidhyapith, Khanpur. Every one of them delivers post to homes.

What the digits of 394641 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 39: the first two digits together name the sub-zone, here the Gujarat Circle.
  • 394: the first three digits name the sorting district, where post for this area is sorted.
  • 641: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Tapi, Gujarat - 394641. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
