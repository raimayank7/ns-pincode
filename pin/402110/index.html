About PIN code 402110

PIN code 402110 belongs to Raigad, Maharashtra. It is used by 9 post offices: Shriwardhan, Bhoste, Galsure, Hareshwar and others. Every one of them delivers post to homes.

What the digits of 402110 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 40: the first two digits together name the sub-zone, here the Maharashtra Circle.
  • 402: the first three digits name the sorting district, where post for this area is sorted.
  • 110: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Raigad, Maharashtra - 402110. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
