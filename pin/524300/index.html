About PIN code 524300

PIN code 524300 belongs to Spsr Nellore, Andhra Pradesh. It is used by 6 post offices: Somasila Hill Colony, Manchalapalli, Padamatikhambampadu, Pathapalli and others. Every one of them delivers post to homes.

What the digits of 524300 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 52: the first two digits together name the sub-zone, here the Andhra Pradesh Circle.
  • 524: the first three digits name the sorting district, where post for this area is sorted.
  • 300: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Spsr Nellore, Andhra Pradesh - 524300. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
