About PIN code 822120

PIN code 822120 belongs to Garhwa, Jharkhand. It is used by 24 post offices: Mohammad Ganj, Baherwa, Belhath, Bhajaniya and others. Every one of them delivers post to homes.

What the digits of 822120 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 82: the first two digits together name the sub-zone, here the Jharkhand Circle.
  • 822: the first three digits name the sorting district, where post for this area is sorted.
  • 120: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Garhwa, Jharkhand - 822120. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
