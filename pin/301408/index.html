About PIN code 301408

PIN code 301408 belongs to Alwar, Rajasthan. It is used by 16 post offices: Machari Chowkrajgarh, Rajgarh (Alwar), Ballupura, Barer and others. 15 offices deliver post to homes: Rajgarh (Alwar), Ballupura, Barer, Binjari, Dhamred and others. The others only serve customers at the counter.

What the digits of 301408 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 30: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 301: the first three digits name the sorting district, where post for this area is sorted.
  • 408: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Alwar, Rajasthan - 301408. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
