About PIN code 805114

PIN code 805114 belongs to Nawada, Bihar. It is used by 7 post offices: Bihar Keshri sri Krishn Singh, Ankari, Bargaon, G B Kendua Konihar and others. Every one of them delivers post to homes.

What the digits of 805114 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 80: the first two digits together name the sub-zone, here the Bihar Circle.
  • 805: the first three digits name the sorting district, where post for this area is sorted.
  • 114: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nawada, Bihar - 805114. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
