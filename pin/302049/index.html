About PIN code 302049

PIN code 302049 belongs to Jaipur, Rajasthan. It is used by 1 post office (NDC Jaipur GPO). It delivers post to homes.

What the digits of 302049 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 30: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 302: the first three digits name the sorting district, where post for this area is sorted.
  • 049: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Jaipur, Rajasthan - 302049. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
