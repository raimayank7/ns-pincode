About PIN code 791122

PIN code 791122 belongs to Upper Subansiri, Arunachal Pradesh. It is used by 153 post offices: Daporijo, Aya Nirin, Bami, Baring and others. Every one of them delivers post to homes.

What the digits of 791122 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 79: the first two digits together name the sub-zone, here the North Eastern Circle.
  • 791: the first three digits name the sorting district, where post for this area is sorted.
  • 122: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Upper Subansiri, Arunachal Pradesh - 791122. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
