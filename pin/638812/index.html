About PIN code 638812

PIN code 638812 belongs to Tiruppur, Tamil Nadu. It is used by 2 post offices: Chengapalli, Virumandampalayam. Every one of them delivers post to homes.

What the digits of 638812 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 63: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 638: the first three digits name the sorting district, where post for this area is sorted.
  • 812: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Tiruppur, Tamil Nadu - 638812. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
