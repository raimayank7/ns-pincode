About PIN code 721127

PIN code 721127 belongs to Medinipur West, West Bengal. It is used by 15 post offices: Garhbeta, Chandeabila Khudiasole, Dhadika, Fulberia and others. Every one of them delivers post to homes.

What the digits of 721127 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 72: the first two digits together name the sub-zone, here the West Bengal Circle.
  • 721: the first three digits name the sorting district, where post for this area is sorted.
  • 127: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Medinipur West, West Bengal - 721127. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
