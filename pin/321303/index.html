About PIN code 321303

PIN code 321303 belongs to Bharatpur, Rajasthan. It is used by 14 post offices: Sewar, Ajau, Bansi Khurd, Bhont and others. Every one of them delivers post to homes.

What the digits of 321303 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 32: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 321: the first three digits name the sorting district, where post for this area is sorted.
  • 303: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Bharatpur, Rajasthan - 321303. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
