About PIN code 570008

PIN code 570008 belongs to Mysuru, Karnataka. It is used by 11 post offices: Mysuru South, Danagalli, Doora, Gopalapura and others. 10 offices deliver post to homes: Mysuru South, Danagalli, Doora, Gopalapura, Gujjegowdanapura and others. The others only serve customers at the counter.

What the digits of 570008 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 57: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 570: the first three digits name the sorting district, where post for this area is sorted.
  • 008: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Mysuru, Karnataka - 570008. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
