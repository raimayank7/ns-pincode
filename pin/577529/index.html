About PIN code 577529

PIN code 577529 belongs to Chitradurga, Karnataka. It is used by 9 post offices: Kondlahalli, B.G.Kere, Devarahalli, Devaredduyhally and others. Every one of them delivers post to homes.

What the digits of 577529 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 57: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 577: the first three digits name the sorting district, where post for this area is sorted.
  • 529: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Chitradurga, Karnataka - 577529. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
