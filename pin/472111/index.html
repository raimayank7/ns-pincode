About PIN code 472111

PIN code 472111 belongs to Tikamgarh, Madhya Pradesh. It is used by 17 post offices: Baldeogarh, Ahar, Airora, Baisa and others. 16 offices deliver post to homes: Baldeogarh, Ahar, Airora, Baisa, Bhelsi and others. The others only serve customers at the counter.

What the digits of 472111 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 47: the first two digits together name the sub-zone, here the Madhya Pradesh Circle.
  • 472: the first three digits name the sorting district, where post for this area is sorted.
  • 111: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Tikamgarh, Madhya Pradesh - 472111. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
