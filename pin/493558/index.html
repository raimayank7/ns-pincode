About PIN code 493558

PIN code 493558 belongs to Mahasamund, Chhattisgarh. It is used by 38 post offices: Saraipali, Amarkot, Badesajapali, Baloda and others. Every one of them delivers post to homes.

What the digits of 493558 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 49: the first two digits together name the sub-zone, here the Chattisgarh Circle.
  • 493: the first three digits name the sorting district, where post for this area is sorted.
  • 558: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Mahasamund, Chhattisgarh - 493558. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
