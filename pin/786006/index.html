About PIN code 786006

PIN code 786006 belongs to Dibrugarh, Assam. It is used by 1 post office (Lepetkata). It delivers post to homes.

What the digits of 786006 mean

  • 7: the postal zone, which covers West Bengal, Odisha, Sikkim, the north-eastern states and the Andaman and Nicobar Islands.
  • 78: the first two digits together name the sub-zone, here the Assam Circle.
  • 786: the first three digits name the sorting district, where post for this area is sorted.
  • 006: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Dibrugarh, Assam - 786006. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
