About PIN code 571250

PIN code 571250 belongs to Kodagu, Karnataka. It is used by 3 post offices: Kutta, Manchalli, Nagarahole. Every one of them delivers post to homes.

What the digits of 571250 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 57: the first two digits together name the sub-zone, here the Karnataka Circle.
  • 571: the first three digits name the sorting district, where post for this area is sorted.
  • 250: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kodagu, Karnataka - 571250. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
