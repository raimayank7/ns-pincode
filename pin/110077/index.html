About PIN code 110077

PIN code 110077 belongs to South West, Delhi. It is used by 5 post offices: Palam Extn (Harijan Basti), Raj Nagar II, Bagdola, Barthal and others. 4 offices deliver post to homes: Raj Nagar II, Bagdola, Barthal, Dhulsiras. The others only serve customers at the counter.

What the digits of 110077 mean

  • 1: the postal zone, which covers Delhi, Haryana, Punjab, Himachal Pradesh, Jammu and Kashmir, Ladakh and Chandigarh.
  • 11: the first two digits together name the sub-zone, here the Delhi Circle.
  • 110: the first three digits name the sorting district, where post for this area is sorted.
  • 077: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: South West, Delhi - 110077. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
