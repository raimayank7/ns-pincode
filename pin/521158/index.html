About PIN code 521158

PIN code 521158 belongs to Krishna, Andhra Pradesh. It is used by 3 post offices: Nimmakuru, Nimmaluru, Palankipadu. Every one of them delivers post to homes.

What the digits of 521158 mean

  • 5: the postal zone, which covers Andhra Pradesh, Telangana and Karnataka.
  • 52: the first two digits together name the sub-zone, here the Andhra Pradesh Circle.
  • 521: the first three digits name the sorting district, where post for this area is sorted.
  • 158: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Krishna, Andhra Pradesh - 521158. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
