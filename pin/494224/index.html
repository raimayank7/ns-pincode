About PIN code 494224

PIN code 494224 belongs to Kondagaon, Chhattisgarh. It is used by 47 post offices: Bhanpuri, Badealnar, Badeamabal, Badejerakhar and others. Every one of them delivers post to homes.

What the digits of 494224 mean

  • 4: the postal zone, which covers Maharashtra, Goa, Madhya Pradesh and Chhattisgarh.
  • 49: the first two digits together name the sub-zone, here the Chattisgarh Circle.
  • 494: the first three digits name the sorting district, where post for this area is sorted.
  • 224: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Kondagaon, Chhattisgarh - 494224. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
