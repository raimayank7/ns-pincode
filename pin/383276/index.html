About PIN code 383276

PIN code 383276 belongs to Sabar Kantha, Gujarat. It is used by 8 post offices: Raigadh, Adpodra, Khambhisar, Mathasulia and others. Every one of them delivers post to homes.

What the digits of 383276 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 38: the first two digits together name the sub-zone, here the Gujarat Circle.
  • 383: the first three digits name the sorting district, where post for this area is sorted.
  • 276: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Sabar Kantha, Gujarat - 383276. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
