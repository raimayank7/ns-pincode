About PIN code 341505

PIN code 341505 belongs to Nagaur, Rajasthan. It is used by 13 post offices: Makrana, Makrana Rs, Makrana S.B, Barwala and others. 11 offices deliver post to homes: Makrana Rs, Barwala, Barwali, Bharnai, Bursu and others. The others only serve customers at the counter.

What the digits of 341505 mean

  • 3: the postal zone, which covers Rajasthan, Gujarat, and Dadra and Nagar Haveli and Daman and Diu.
  • 34: the first two digits together name the sub-zone, here the Rajasthan Circle.
  • 341: the first three digits name the sorting district, where post for this area is sorted.
  • 505: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Nagaur, Rajasthan - 341505. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
