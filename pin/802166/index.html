About PIN code 802166

PIN code 802166 belongs to Bhojpur, Bihar. It is used by 8 post offices: Umraonganj, Bahoranpur, Barakhrauni, Chamarpur and others. Every one of them delivers post to homes.

What the digits of 802166 mean

  • 8: the postal zone, which covers Bihar and Jharkhand.
  • 80: the first two digits together name the sub-zone, here the Bihar Circle.
  • 802: the first three digits name the sorting district, where post for this area is sorted.
  • 166: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Bhojpur, Bihar - 802166. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
