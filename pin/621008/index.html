About PIN code 621008

PIN code 621008 belongs to Tiruchirappalli, Tamil Nadu. It is used by 9 post offices: Sikkathambur, Govindapuram, Kalingamudayanpatti, Murukkur and others. Every one of them delivers post to homes.

What the digits of 621008 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 62: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 621: the first three digits name the sorting district, where post for this area is sorted.
  • 008: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Tiruchirappalli, Tamil Nadu - 621008. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
