About PIN code 622401

PIN code 622401 belongs to Pudukkottai, Tamil Nadu. It is used by 6 post offices: Koppanapatti, Alavayal, Melamelanilai, Nagarapatti and others. Every one of them delivers post to homes.

What the digits of 622401 mean

  • 6: the postal zone, which covers Tamil Nadu, Kerala, Puducherry and Lakshadweep.
  • 62: the first two digits together name the sub-zone, here the Tamilnadu Circle.
  • 622: the first three digits name the sorting district, where post for this area is sorted.
  • 401: the last three digits name the delivery post office within that sorting district.

Writing this address

Write the PIN code on the last line, after the town or district and state, in clear digits: Pudukkottai, Tamil Nadu - 622401. A correct PIN code matters more than the district or state name, because post is sorted by PIN code. How to write an address
