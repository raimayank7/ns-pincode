PIN Code

About PIN Code

Nivesh Sahayak PIN Code is a free finder for the postal PIN codes of India: 19,486 PIN codes and 165,521 post offices in 754 districts. Type a PIN code to see where it is, or type a place to find its PIN code.

Where the data comes from

The list is the All India Pincode Directory published by the Department of Posts (India Post) on the Open Government Data Platform, data.gov.in, under the Government Open Data Licence - India. The copy on this site was taken on 11 November 2026. India Post opens, merges and renames post offices from time to time, so a recent change may not show yet. For the official answer use the PIN code search on indiapost.gov.in.

Map positions come from the same list. They mark the post office, are missing for some offices, and are approximate.

Who makes it

This site is one of the free tools of Nivesh Sahayak. Every Nivesh Sahayak tool is free to use, needs no login and always will be free. If it helps you, you can support the work.

Found a mistake?

Data of this size always has a few errors. Please tell us the page and what is wrong, and we will check it against the official source.
