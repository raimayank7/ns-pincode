How to use it

  1. You have a PIN code and want to know the place: type the 6 digits in the first box and press Check PIN code.
  2. You have a place and want its PIN code: type the post office, village or locality in the second box and tap the right one in the list.
  3. Not sure of the post office? Choose your state, then your district, and search the list.
  4. Tap Copy or Share to send the PIN code on WhatsApp.

How a PIN code is built

Take 141001 (Ludhiana). The first digit, 1, is the postal zone in the north. The first two, 14, name the sub-zone (Punjab). The first three, 141, name the sorting district. The last three, 001, name the delivery post office; 001 is usually the head post office of the town.

Questions

What is a PIN code?

PIN means Postal Index Number. It is the 6-digit code India Post uses to sort and deliver post. Every delivery post office has one, and several small post offices can share the same PIN code.

How do I find the PIN code of my area?

Type the name of your post office, village or locality in the second box on this page. If you do not know the post office, choose your state and district and look through the list.

Can one PIN code cover many villages?

Yes. A PIN code belongs to a delivery post office, and that office can serve many villages or city localities. All of them write the same PIN code.

Is a PIN code the same as a ZIP code?

They do the same job. ZIP code is the name used in the United States. If a website asks an Indian address for a ZIP or postal code, type your PIN code.

How current is this list?

It is India Post's directory as published on data.gov.in, taken on 11 November 2026.
